## Lingkungan

Daftar hanya-baca dari variabel yang dibaca NPMpro saat container dimulai. Anda tidak dapat mengubahnya di sini. Untuk mengubah salah satunya, edit file compose atau template container Anda dan buat ulang container.

Nilai kata sandi, alamat email, dan kunci tidak pernah ditampilkan. Anda hanya melihat apakah variabel itu diatur atau tidak.

- **Pengaturan yang diatur oleh variabel lingkungan**: pengaturan yang saat ini dikunci oleh sebuah variabel di Pengaturan, dengan variabel dan bagiannya. Hapus variabel untuk mengelola pengaturan itu di UI lagi.
- **Grup variabel**: variabel startup seperti port, binding, pengguna, TLS dan sakelar nginx, modul dan PHP, database dan startup pertama, serta akun sertifikat. Setiap baris menampilkan variabel, nilai atau defaultnya, status (diatur, atau tidak diatur), dan deskripsi. Beberapa variabel juga merupakan pengaturan; barisnya menyebut "pengaturan".

Selengkapnya di wiki: Configuration.
