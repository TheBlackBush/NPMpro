## میزبان پراکسی چیست؟

میزبان پراکسی درِ ورودی یک سرویس وب است. بازدیدکنندگان دامنه شما را در NPMpro باز می‌کنند و NPMpro درخواست را به سرویس پشت آن می‌فرستد. همچنین می‌تواند برای سرویس‌هایی که TLS (HTTPS) ندارند آن را اضافه کند. میزبان‌های پراکسی رایج‌ترین کاربرد NPMpro هستند.

از **شبیه‌سازی** در منوی میزبان استفاده کنید تا میزبان را در یک پنجره افزودن جدید کپی کنید. کپی بدون نام‌های دامنه شروع می‌شود، چون یک دامنه فقط می‌تواند متعلق به یک میزبان فعال باشد.

### جزئیات

- **نام‌های دامنه**: نام‌هایی که بازدیدکنندگان استفاده می‌کنند. الزامی است. برای گواهی جدید، wildcardها (`*.example.com`) به چالش DNS نیاز دارند.
- **پروتکل (Scheme)**: نحوه گفتگوی NPMpro با سرویس: `http://`، `https://`، `grpc://`، `grpcs://`، `path` (ارائه فایل یا PHP از یک پوشه) یا `empty` (بدون upstream). پیش‌فرض `http://`. تغییر پروتکل گزینه‌هایی را که با آن سازگار نیستند خاموش می‌کند.
- **نام میزبان / IP / مسیر مقصد**: نشانی سرویس. می‌توانید یک زیرمسیر اضافه کنید، مثلاً `127.0.0.1/path`. با `path` یک پوشه وارد کنید. فایل‌های خود را زیر `/var/www` مانت کنید؛ فقط مدیران می‌توانند از پوشه‌ای بیرون از آن استفاده کنند. نامی که با `cu_` شروع شود به بلوک upstream nginx خودتان اشاره می‌کند (به Load balancing در ویکی نگاه کنید).
- **پورت مقصد**: اختیاری. با `path` نسخه PHP است.
- **گروه**: برچسبی آزاد که فهرست‌های بلند را مرتب نگه می‌دارد.
- **گزینه‌ها** (همه به‌طور پیش‌فرض خاموش):
  - **ارسال هدر noindex و مسدود کردن برخی user agentهای ربات**: از موتورهای جست‌وجو می‌خواهد سایت را ایندکس نکنند و برخی خزنده‌ها را مسدود می‌کند.
  - **غیرفعال کردن CrowdSec AppSec**: CrowdSec AppSec را فقط برای این میزبان خاموش می‌کند. فقط وقتی اثر دارد که AppSec راه‌اندازی شده باشد.
  - **غیرفعال کردن بافر درخواست** و **غیرفعال کردن بافر پاسخ**: برای upstreamهای http و https. بافر را روشن نگه دارید مگر آنکه روی اتصالی سریع و پایدار استریم کنید یا فایل‌های بزرگ آپلود کنید. خاموش کردن بافر درخواست، AppSec را هم خاموش می‌کند.
  - **فعال کردن فشرده‌سازی توسط upstream**: به سرویس اجازه می‌دهد پاسخ‌های خود را خودش فشرده کند. آن را خاموش نگه دارید مگر آنکه سرویس نیاز داشته باشد. برای `path` و `empty` نیست.
  - **فعال کردن fancyindex**: وقتی پوشه‌ای فایل index ندارد فهرست فایل‌ها را نشان می‌دهد. فقط برای `path`.
- **X-Frame-Options**: `SAMEORIGIN` (پیش‌فرض)، `DENY`، `none` (هدر را حذف می‌کند) یا `upstream` (آنچه سرویس می‌فرستد را نگه می‌دارد).
- **Auth Request**: یک ورود یا بررسی ربات را جلوی میزبان می‌گذارد (Anubis، Tinyauth، OAuth2 Proxy، VoidAuth، Authelia، Authentik). پیش‌فرض `none`. **Upstream مربوط به Auth Request** اختیاری است؛ خالی بودن آن از پیش‌فرض تنظیمات، احراز هویت ارجاعی استفاده می‌کند.
- **فهرست‌های دسترسی سراسری**: **قابل دسترسی عمومی** (پیش‌فرض، بدون ورود) یا **سفارشی**، یک یا چند فهرست دسترسی.

وب‌سوکت‌ها همیشه روشن هستند.

### مسیرهای سفارشی (Location)

یک مسیر، یک path از میزبان (مثلاً `/api/`) را به سرویسی دیگر می‌فرستد. هر کدام **فعال شد**، یک path با نوع مطابقت اختیاری (`=`، `~`، `~*`، `^~` یا `@`)، پروتکل، میزبان، پورت، گزینه‌ها، Auth Request و فهرست‌های دسترسی خودش را دارد. فهرست دسترسی آن می‌تواند **سراسری** باشد که از فهرست‌های میزبان استفاده می‌کند. Auth Request میزبان را به ارث نمی‌برد. به انتهای path یک اسلش اضافه کنید مگر آنکه مطابقت پیشوندی بخواهید. مدیران می‌توانند با دکمه چرخ‌دنده برای هر مسیر پیکربندی سفارشی nginx اضافه کنند.

### TLS

- **گواهی TLS**: هیچ، درخواست گواهی جدید، یا یک گواهی موجود. گزینه‌های زیر به گواهی نیاز دارند.
- **گواهی mTLS**: یک مرجع گواهی کلاینت. **اختیاری کردن mTLS** به بازدیدکنندگان بدون گواهی اجازه ورود می‌دهد. **عبور mTLS از Auth Request** به بازدیدکنندگان دارای گواهی معتبر اجازه می‌دهد Auth Request را رد کنند.
- **اجبار به HTTPS** HTTP را به HTTPS تغییر مسیر می‌دهد. **پشتیبانی از HTTP/3** اجازه HTTP/3 (QUIC) را می‌دهد.
- **HSTS فعال (2 سال)**: به اجبار به HTTPS نیاز دارد. **HSTS زیردامنه‌ها+Preload** به HSTS نیاز دارد.
- برای گواهی جدید: **استفاده مجدد از کلید (توصیه نمی‌شود)** و **استفاده از چالش DNS (DNS Challenge)**، همراه با ارائه‌دهنده، اعتبارنامه و ثانیه‌های انتشار.

### پیشرفته

پیکربندی سفارشی nginx برای کل میزبان (بلوک server) و برای مسیر اصلی `location /`. فقط مدیران می‌توانند آن را تغییر دهند.

بیشتر در ویکی: Host options.
