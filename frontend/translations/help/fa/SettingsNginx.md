## nginx

تنظیمات خود nginx که روی همه میزبان‌ها اعمال می‌شود: چند worker اجرا کند، قوانین TLS و ماژول‌های اختیاری. ذخیره پیکربندی را آزمایش می‌کند و nginx را reload می‌کند. پیکربندی‌ای که در آزمایش رد شود اعمال نمی‌شود.

متغیری که روی کانتینر تنظیم شده باشد بر UI برتری دارد و فیلد را قفل می‌کند (فیلد یک نشان قفل مانند «تنظیم‌شده توسط NGINX_WORKER_PROCESSES» نشان می‌دهد). برای هر چیزی که در کانتینر تنظیم نشده از UI استفاده کنید. هر تنظیم اینجا پس از reload nginx که ذخیره اجرا می‌کند اعمال می‌شود.

### Workerها

- **فرایندهای worker**: «خودکار (یکی برای هر thread پردازنده)» یا عددی تا تعداد threadهای پردازنده‌ای که کانتینر می‌بیند. پیش‌فرض: یکی برای هر thread، حداکثر 4. متغیر: `NGINX_WORKER_PROCESSES`.
- **اتصالات برای هر worker**: اتصال‌های بازی که هر worker هم‌زمان مدیریت می‌کند، 64 تا 65535. پیش‌فرض: 512. متغیر: `NGINX_WORKER_CONNECTIONS`.
- **مهلت خاموش شدن worker**: workerهای قدیمی پس از reload تا چه مدت اتصال‌هایشان را نگه می‌دارند. یک مقدار زمانی nginx مانند `30s`، `10m` یا `1h`؛ `0` یعنی بدون محدودیت. پیش‌فرض: `1h`. متغیر: `NGINX_WORKER_SHUTDOWN_TIMEOUT`.

### ثبت لاگ

- **ثبت خطاهای «فایل پیدا نشد»**: برای هر درخواست فایل ناموجود یک خط لاگ error می‌نویسد. پیش‌فرض: خاموش. متغیر: `NGINX_LOG_NOT_FOUND`.

### TLS برای همه میزبان‌ها

خاموش کردن TLS 1.2 یا منحنی‌های NIST P مرورگرها و کلاینت‌های قدیمی‌تر را بیرون می‌گذارد. TLS 1.3 همیشه روشن است.

- **مجاز کردن TLS 1.2**: پیش‌فرض روشن. متغیر: `NGINX_DISABLE_TLS12` (معکوس: `true` برای TLS 1.2 را خاموش می‌کند).
- **فقط تبادل کلید پساکوانتومی**: فقط X25519MLKEM768 را مجاز می‌کند که به کلاینت جدید نیاز دارد. TLS 1.2 و منحنی‌های NIST P را خاموش می‌کند و تا وقتی روشن است آن‌ها را قفل می‌کند. پیش‌فرض: خاموش. متغیر: `NGINX_FORCE_X25519MLKEM768`.
- **مجاز کردن منحنی‌های NIST P**: secp521r1، secp384r1 و prime256v1 برای تبادل کلید، در کنار X25519. پیش‌فرض: روشن. متغیر: `NGINX_TRUST_SECPR1`.
- **مجاز کردن امضاهای RSA PKCS#1**: برای کلاینت‌های قدیمی که نمی‌توانند از RSA-PSS استفاده کنند. پیش‌فرض: خاموش. متغیر: `NGINX_TRUST_RSA_PKCS1`.

### ماژول‌ها

همه به‌طور پیش‌فرض خاموش‌اند. یک ماژول را فقط وقتی روشن کنید که پیکربندی سفارشی شما به آن نیاز دارد. خاموش کردن ماژولی که پیکربندی سفارشی هنوز از آن استفاده می‌کند آزمایش nginx را ناموفق می‌کند.

- **njs (JavaScript)**: دستورهای `js_*`. متغیر: `NGINX_LOAD_NJS_MODULE`.
- **احراز هویت LDAP**: دستورهای `auth_ldap`. متغیر: `NGINX_LOAD_LDAP_MODULE`.
- **upstreamهای NTLM**: `ntlm` در بلوک‌های upstream. متغیر: `NGINX_LOAD_NTLM_MODULE`.
- **وضعیت ترافیک میزبان مجازی**: دستورهای `vhost_traffic_status_*`. متغیر: `NGINX_LOAD_VHOST_TRAFFIC_STATUS_MODULE`.
