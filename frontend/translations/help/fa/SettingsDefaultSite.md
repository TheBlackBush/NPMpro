## سایت پیش‌فرض

سایت پیش‌فرض پاسخی است که nginx وقتی می‌دهد که بازدیدکننده با نام میزبانی که هیچ میزبانی از آن استفاده نمی‌کند، یا با نشانی IP سرور، به NPMpro برسد. پاسخ را اینجا انتخاب کنید. روی همه نام‌های ناشناس اعمال می‌شود.

ذخیره ابتدا انتخاب جدید را با nginx آزمایش می‌کند. اگر آزمایش شکست بخورد، چیزی ذخیره نمی‌شود، سایت پیش‌فرض قبلی می‌ماند و خطای nginx در لاگ کانتینر است.

- **صفحه تبریک** (پیش‌فرض): صفحه خوش‌آمدگویی NPMpro را نشان می‌دهد.
- **صفحه 404**: با صفحه 404 Not Found پاسخ می‌دهد.
- **بدون پاسخ (444)**: اتصال را بدون هیچ پاسخی می‌بندد. از آن استفاده کنید تا چیزی برای اسکنرها نمایان نشود. درخواست‌های HTTPS برای نام‌های ناشناس در handshake مربوط به TLS رد می‌شوند.
- **تغییر مسیر**: بازدیدکنندگان را با تغییر مسیر موقت (302) به نشانی دیگری می‌فرستد. یک URL کامل `http://` یا `https://` بدون فاصله، نقل‌قول یا `; { } #` وارد کنید، حداکثر 255 نویسه.
- **HTML سفارشی**: صفحه HTML خودتان را نشان می‌دهد. **HTTP Status Code** زیر آن اختیاری است، از 400 تا 599. برای 200 (OK) خالی بگذارید.

برای هر انتخاب به جز بدون پاسخ، درخواست‌های HTTP ساده به نام‌های ناشناس ابتدا به HTTPS تغییر مسیر می‌یابند و درخواست‌های HTTPS از گواهی‌ای استفاده می‌کنند که در تنظیمات، گواهی‌ها و TLS به‌عنوان **گواهی پیش‌فرض** انتخاب شده است.

این بخش متغیر محیطی ندارد، پس تغییر هنگام ذخیره اعمال می‌شود.
