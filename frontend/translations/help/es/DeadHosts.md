## ¿Qué es un Host 404?

Un Host 404 es simplemente una configuración de host que muestra una página 404.

Esto puede ser útil cuando tu dominio está listado en los motores de búsqueda y deseas
proporcionar una página de error más agradable o específicamente para indicar a los indexadores de búsqueda que
las páginas del dominio ya no existen.

Otro beneficio de tener este host es rastrear los registros de visitas a él y
ver los referentes.

Una **Descripción** opcional (una línea) dice para qué sirve el host; se muestra bajo los nombres de dominio en la lista. Las **Etiquetas** (hasta 10) identifican el host; se hace clic en una de ellas en la lista para filtrar por ella.

**Página** (404) elige lo que ven los visitantes: **Ajuste global** (la página 404 de Configuración, Páginas de destino), la **Página de error 404** o una **Página personalizada** solo para este host (pega o sube un archivo HTML).
