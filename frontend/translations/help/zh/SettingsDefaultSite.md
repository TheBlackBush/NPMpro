## 默认站点

默认站点是当访问者使用没有任何主机使用的主机名，或使用服务器的 IP 地址访问 NPMpro 时，nginx 给出的应答。请在此选择应答方式。它适用于所有未知名称。

保存时会先用 nginx 测试新的选择。如果测试失败，则不会保存任何内容，之前的默认站点保持不变，nginx 错误会记录在容器日志中。

- **成功页面**（默认）：显示 NPMpro 欢迎页面。
- **错误页面 (404)**：以 404 Not Found 页面应答。
- **无响应 (444)**：不作任何应答，直接关闭连接。用它可以让扫描器看不到任何内容。对未知名称的 HTTPS 请求会在 TLS 握手期间被拒绝。
- **重定向**：通过临时重定向 (302) 把访问者发送到另一个地址。请输入完整的 `http://` 或 `https://` URL，不含空格、引号或 `; { } #`，最多 255 个字符。
- **自定义 HTML**：显示你自己的 HTML 页面。其下的 **HTTP 状态码**为可选，范围为 400 到 599。留空表示 200 (OK)。

除“无响应”外，对每个选项而言，对未知名称的普通 HTTP 请求都会先被重定向到 HTTPS，而 HTTPS 请求使用在设置的“证书与 TLS”中选为**默认证书**的证书。

本区域没有环境变量，因此更改在保存时生效。
