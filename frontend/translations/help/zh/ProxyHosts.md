## 什么是代理主机？

代理主机是 Web 服务的前门。访问者在 NPMpro 中打开你的域名，NPMpro 再把请求转发给背后的服务。它还可以为自身没有 TLS 的服务加上 TLS（HTTPS）。代理主机是 NPMpro 最常见的用法。

使用主机菜单中的**克隆**，可以把主机复制到一个新的添加窗口。副本不带域名，因为一个域名只能属于一个已启用的主机。

### 详情

- **域名**：访问者使用的名称。必填。对于新证书，通配符（`*.example.com`）需要使用 DNS 验证。
- **协议 (Scheme)**：NPMpro 与服务通信的方式：`http://`、`https://`、`grpc://`、`grpcs://`、`path`（从文件夹提供文件或 PHP）或 `empty`（无上游）。默认为 `http://`。更改协议会关闭与之不匹配的选项。
- **转发主机名 / IP / 路径**：服务的地址。可以添加子路径，例如 `127.0.0.1/path`。使用 `path` 时，改为输入一个文件夹。请把文件挂载到 `/var/www` 下；只有管理员可以使用其外部的文件夹。以 `cu_` 开头的名称指向你自己的 nginx 上游块（参见 wiki 中的 Load balancing）。
- **转发端口**：可选。使用 `path` 时，它表示 PHP 版本。
- **分组**：自由填写的标签，用来让长列表保持整洁。
- **选项**（默认均为关闭）：
  - **发送 noindex 头并阻止部分机器人 User-Agent**：请求搜索引擎不要索引该站点，并阻止部分爬虫。
  - **禁用 Crowdsec Appsec**：仅对此主机关闭 CrowdSec AppSec。只有已设置 AppSec 时才有效果。
  - **禁用请求缓冲**和**禁用响应缓冲**：用于 http 和 https 上游。除非你要在快速稳定的链路上进行流式传输或上传大文件，否则请保持缓冲开启。关闭请求缓冲也会关闭 AppSec。
  - **允许上游进行压缩**：让服务自己压缩响应。除非服务需要，否则请保持关闭。不适用于 `path` 和 `empty`。
  - **启用 fancyindex**：当文件夹没有索引文件时显示文件列表。仅适用于 `path`。
- **X-Frame-Options**：`SAMEORIGIN`（默认）、`DENY`、`none`（移除该头）或 `upstream`（保留服务发送的内容）。
- **认证请求**：在主机前面加上登录或机器人检查（Anubis、Tinyauth、OAuth2 Proxy、VoidAuth、Authelia、Authentik）。默认为 `none`。**认证请求上游**为可选；留空时使用设置中“转发认证”里的默认值。
- **全局访问列表**：**公开可访问**（默认，无需登录）或**自定义**，即一个或多个访问列表。

WebSocket 始终开启。

### 自定义位置

位置把主机的某一个路径（例如 `/api/`）发送到另一个服务。每个位置都有**已启用**、一个路径（可带匹配类型：`=`、`~`、`~*`、`^~` 或 `@`）、自己的协议、主机、端口、选项、认证请求和访问列表。它的访问列表可以是**全局**，即使用主机的列表。它不会继承主机的认证请求。除非你想要前缀匹配，否则请在路径末尾加上斜杠。管理员可以通过齿轮按钮为每个位置添加自定义 nginx 配置。

### TLS

- **TLS 证书**：无、申请新证书，或选择已有证书。下面的选项需要证书。
- **mTLS 证书**：客户端证书颁发机构。**将 mTLS 设为可选**可让没有证书的访问者进入。**mTLS 绕过认证请求**可让持有有效证书的访问者跳过认证请求。
- **强制 HTTPS**会把 HTTP 重定向到 HTTPS。**HTTP/3 支持**允许使用 HTTP/3 (QUIC)。
- **启用 HSTS（2 年）**：需要强制 HTTPS。**HSTS 子域名 + Preload** 需要 HSTS。
- 对于新证书：**复用密钥（不推荐）**和**使用DNS验证**，并填写提供商、凭据和传播等待秒数。

### 高级

整个主机（server 块）和主位置 `location /` 的自定义 nginx 配置。只有管理员可以更改。

更多内容见 wiki：Host options。
