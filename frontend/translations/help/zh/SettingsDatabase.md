## 数据库

NPMpro 用来保存主机、证书、用户、日志和统计数据的数据库。默认是 SQLite，即单个文件，这也是推荐的选择。你可以在这里把所有数据迁移到 MySQL、MariaDB、PostgreSQL 或新的 SQLite 文件。迁移不会改变正在使用的数据库。

### 正在使用的数据库

显示引擎和版本、位置、大小以及连接的**来源**：**默认**（SQLite 文件 `/data/npmpro/database.sqlite`）、**数据库设置文件**（`/data/npmpro/database.json`，由迁移写入）或**环境变量**（`DB_MYSQL_*` 或 `DB_POSTGRES_*` 变量）。迁移之后，它会显示迁移的时间以及从哪个引擎迁移而来。

### 表

列出每个表的行数和大小。该卡片可以折叠。

### 迁移到另一个数据库

请先在你的服务器上创建一个空数据库和一个可以创建表的用户；NPMpro 不会创建数据库。要求：MySQL 8.0、MariaDB 10.6 或 PostgreSQL 13 及以上版本。

1. 选择**引擎**，并输入**主机**、**端口**、**数据库名称**、**用户**和**密码**。如果服务器需要，请开启 **使用 TLS**（对于 MySQL 和 MariaDB，还可以**检查服务器证书**和**检查服务器名称**）。迁移到 SQLite 不需要任何设置：它会在 `/data/npmpro` 中创建一个新文件。
2. **测试连接**。它会检查版本、数据库是否为空，以及用户是否可以创建表。它不会更改任何内容。
3. 点击**迁移**，然后输入它要求的单词，并点击**立即迁移**。

NPMpro 会暂停更改、创建安全备份、创建表、复制并检查每一行，然后在新数据库上重新启动。你的站点会继续提供服务。NPMpro 再次响应时页面会重新加载，你可能需要重新登录。

如果某一步失败，NPMpro 会继续使用原来的数据库，窗口会指出停止的步骤。旧数据库不会被删除，所以你可以回退：删除 `/data/npmpro/database.json` 并重启容器。

如果连接来自 `DB_MYSQL_*` 或 `DB_POSTGRES_*` 变量，则本区域为只读。要迁移，请先创建备份，把这些变量指向新数据库，重启，然后恢复备份。

更多内容见 wiki：Database。
