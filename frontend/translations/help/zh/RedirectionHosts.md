## 什么是重定向主机？

重定向主机会把一个域名的访问者发送到另一个地址。当网站更换域名而旧链接仍需有效时，或要把 `www` 指向主域名时，可以使用它。

使用主机菜单中的**克隆**，可以把主机复制到一个新的添加窗口。副本不带域名，因为一个域名只能属于一个已启用的主机。

### 详情

- **域名**：被重定向的名称。必填。通配符只有在为新证书使用 DNS 验证时才允许。
- **协议 (Scheme)**：目标的协议。默认为“保持（与请求相同）”，沿用访问时的 `http` 或 `https`。也可以选择 `http` 或 `https`。
- **转发域名**：访问者被发送到的域名，例如 `example.com`。必填。
- **HTTP 状态码**：响应代码。默认为 301 Moved permanently。其他选项有 302 Moved temporarily、303 See other、307 Temporary redirect 和 308 Permanent redirect。如果是永久迁移，请使用 301 或 308；浏览器和搜索引擎会记住它们。
- **分组**：自由填写的标签，用来让长列表保持整洁。可选择已在使用的名称，或输入新名称。
- **保留路径**（默认关闭）：把原始路径和查询参数附加到目标地址。开启后，`old.example/a?b=1` 会跳转到 `new.example/a?b=1`。关闭时，所有访问者都会到达目标的起始页。

### TLS

- **TLS 证书**：无、申请新证书，或选择已有证书。下面的选项需要证书。
- **mTLS 证书**：客户端证书颁发机构。**将 mTLS 设为可选**可让没有客户端证书的访问者进入。
- **强制 HTTPS**：先把 HTTP 重定向到 HTTPS。
- **HTTP/3 支持**：允许使用 HTTP/3 (QUIC)。
- **启用 HSTS（2 年）**：需要强制 HTTPS。**HSTS 子域名 + Preload** 需要 HSTS。
- 对于新证书：**复用密钥（不推荐）**和**使用DNS验证**，并填写提供商、凭据和传播等待秒数。

所有 TLS 选项默认均为关闭。
