## GeoIP

NPMpro 会自行下载免费的 MaxMind GeoLite2 数据库，并在你的服务器上查询国家和网络，因此访问者的 IP 不会被发送到任何地方。你不需要单独的 geoipupdate 容器。这些数据库用于监控的地图和列表、GoAccess 以及 nginx 国家规则。

在容器上设置的变量优先于界面，并会锁定对应字段（字段显示“由环境变量设置”）。凡是没有在容器中设置的内容，请在界面中设置。保存后会在后台开始下载，完成后下方的状态会更新。

### MaxMind 账户

你需要一个免费的 MaxMind 账户和一个许可证密钥（在 MaxMind 中：Account，Manage license keys）。页面上有注册链接。

- **账户 ID**：变量 `GEOIP_ACCOUNT_ID`。
- **许可证密钥**：加密存储，且不会再次显示。如果无法解密已保存的密钥，请重新输入。变量：`GEOIP_LICENSE_KEY`。

### 数据库

- **GeoLite2 Country**：用于地图、国家列表和 nginx 国家规则的国家数据。默认开启。
- **GeoLite2 ASN**：用于网络列表的网络（AS 编号和名称）。默认开启。
- **GeoLite2 City**：可选，用于 GoAccess 的城市数据。下载量要大得多。默认关闭。

变量：`GEOIP_EDITIONS`，以空格分隔，例如 `GeoLite2-Country GeoLite2-ASN`。如果没有选择任何数据库，则不会下载或更新任何内容，已下载的数据库会保留。

### 状态

显示上次更新和上次错误。NPMpro 会在你更改账户或数据库时、点击**立即更新**时更新数据库，并且每 3 天自动更新一次。自动更新失败后，会在 24 小时后重试。**立即更新**需要已保存的账户 ID 和许可证密钥。

没有数据库时，地图以及国家和网络列表会被隐藏；其余功能正常。

更多内容见 wiki：Monitoring。
