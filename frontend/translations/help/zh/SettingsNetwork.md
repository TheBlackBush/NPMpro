## 网络

告诉 NPMpro，位于它前面的哪些代理对真实客户端地址是可信的。没有这项设置时，日志、访问列表和 CrowdSec 看到的是代理的地址，而不是访问者的地址。

在容器上设置的变量优先于界面，并会锁定对应字段（字段上会显示锁定徽章，例如“由 TRUST_IP 设置”）。凡是没有在容器中设置的内容，请在界面中设置。

- **受信任的代理 IP**：每行一个 IPv4 或 IPv6 地址或 CIDR 范围，例如 `10.0.0.0/8`、`192.168.1.5` 或 `fd00::/8`。来自这些地址的请求可以通过 `X-Forwarded-For` 传递真实的客户端 IP。适用于直接位于 NPMpro 前面的负载均衡器或隧道。默认值：空（不信任任何人）。变量：`TRUST_IP`（以空格分隔）。在保存时执行的 nginx 重新加载之后生效。
- **信任 Cloudflare**：获取 Cloudflare 的 IP 范围，定期刷新并信任它们，这样 nginx 就能看到 Cloudflare 背后的真实客户端 IP。默认值：关闭。变量：`TRUST_CLOUDFLARE`。在保存时执行的 nginx 重新加载之后生效。请先阅读 wiki 中关于 Cloudflare 的说明（Security）：把 Cloudflare 放在 NPMpro 前面会带来隐私和安全方面的代价。

只信任你自己控制或完全可靠的地址。受信任的地址可以声称自己是任何访问者。

如果保存时 nginx 测试失败，则不会保存任何内容，并会显示 nginx 的消息。

更多内容见 wiki：Security。
