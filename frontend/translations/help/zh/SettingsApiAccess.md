## API 访问

所有用户的全部 API 令牌。只有管理员能看到此页面。

令牌由其所有者在用户菜单的 **API 令牌**中创建。这里显示每个令牌的所有者、权限、过期时间、最后使用时间和创建时间。

- **吊销**会立即停止令牌。使用它的脚本和 AI 助手之后会收到身份验证错误。
- 令牌的权限不会超过其所有者。管理员的令牌只有在开启其**管理员**开关时才以管理员身份操作，并且没有任何令牌可以管理用户。
- 令牌的创建、吊销、过期和首次使用都会记入审计日志，令牌名称显示在用户旁边。

**API 文档**会在新标签页中打开每个端点的 API 参考，并显示发送令牌所用的请求头。**MCP 服务器**显示端点、Claude Code 以及 Claude Desktop 和其他客户端的设置方法，以及令牌可使用的工具。
