## 日志与监控

日志文件、GoAccess 日志报告，以及监控页面背后的流量统计。

在容器上设置的变量优先于界面，并会锁定对应字段（字段上会显示锁定徽章，例如“由 LOGROTATE 设置”，统计则显示“由环境变量设置”）。凡是没有在容器中设置的内容，请在界面中设置。标有“需要重启”的设置会立即保存，但在容器启动时才读取；本区域随后会在“重启容器以应用”下列出它们。

### 日志文件

- **写入日志文件**：把 nginx 的错误日志、stream 日志和访问日志写入 `/data/nginx/logs`，并每天轮换。默认值：关闭。变量：`LOGROTATE`。在保存时执行的 nginx 重新加载之后生效。GoAccess 运行期间它会保持开启。
- **保留的日志轮换数**：在删除最旧的文件之前保留多少个已轮换的日志文件，1 到 1000。默认值：3。变量：`LOGROTATIONS`。立即生效。

### GoAccess

- **GoAccess 报告**：在 Web 界面的 `/goaccess` 下运行 GoAccess，这是面向管理员的 Web 日志报告。默认值：关闭。变量：`GOA`。重启容器后生效。它不会开启流量统计。

开启报告后，会显示以下选项。它们都在重启容器后生效。一个变量 `GOACLA` 可以用你自己的 GoAccess 选项取代所有这些选项，并将其锁定。

- **报告数据保留期**：1 到 366 天。默认值：30。
- **匿名化访客 IP**：关闭、级别 1（默认）、级别 2（强）或级别 3（严格）。级别 1 隐藏 IPv4 的最后一个字节（IPv6 的最后 64 位），级别 2 隐藏两个字节（80 位），级别 3 隐藏三个字节（96 位）。
- **去除查询字符串**：从报告中的 URL 里移除查询字符串，因此 URL 中的令牌不会被存储。默认值：开启。
- **完整操作系统版本**：显示完整版本，而不只是系统系列。默认值：开启。
- **解析主机名**：查询访客 IP 对应的主机名。这会为此发送 DNS 查询。默认值：开启。

### 监控

这些设置控制监控页面的流量选项卡。保存后全部立即生效。变量：`TRAFFIC_STATS`、`TRAFFIC_RETENTION_DAYS`、`TRAFFIC_SHOW_IPS`、`TRAFFIC_UNIQUE_VISITORS`、`TRAFFIC_VISITORS_CAP`。

- **流量统计**：读取 nginx 访问日志，并按主机、状态、国家和网络统计请求数。默认值：关闭。关闭后会停止新的统计；已存储的统计会保留到过期，除非你在对话框中勾选“同时删除已存储的统计数据”。
- **统计数据保留**：7 到 365 天。默认值：30。每分钟的数据保留 24 小时，每小时的数据保留这么多天。
- **显示访客 IP**：按小时存储访客 IP，以便列出排名靠前的 IP。默认值：关闭，出于隐私考虑。关闭后会删除已存储的 IP。
- **统计独立访客**：按主机和日期存储每个访客 IP 的带密钥哈希，以统计独立访客。默认值：关闭。关闭后会删除这些哈希。
- **每个主机每天的访客上限**：1000 到 1000000。默认值：100000。达到上限的主机当天会停止统计新访客，并显示加号。

国家和网络需要 GeoIP 数据库（设置，GeoIP）。
