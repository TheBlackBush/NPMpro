## API アクセス

全ユーザーのすべての API トークンです。このページは管理者だけに表示されます。

トークンは所有者がユーザーメニューの **API トークン**で作成します。ここでは各トークンの所有者、権限、有効期限、最終使用日時、作成日時を確認できます。

- **取り消し**はトークンをすぐに停止します。そのトークンを使うスクリプトや AI アシスタントは、以後認証エラーになります。
- トークンの権限が所有者を超えることはありません。管理者のトークンは **管理者**スイッチをオンにした場合のみ管理者として動作し、ユーザーを管理できるトークンはありません。
- トークンの作成、取り消し、期限切れ、初回使用は監査ログに記録され、ユーザーの横にトークン名が表示されます。

**API ドキュメント**は、すべてのエンドポイントの API リファレンスを新しいタブで開き、トークンを送信するヘッダーを表示します。**MCP サーバー**は、エンドポイント、Claude Code と Claude Desktop などのクライアントの設定方法、トークンが使えるツールを表示します。
