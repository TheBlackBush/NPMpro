## GeoIP

NPMpro は無料の MaxMind GeoLite2 データベースを自分でダウンロードし、国とネットワークの検索をサーバー上で行うため、訪問者の IP がどこにも送信されることはありません。別の geoipupdate コンテナは不要です。データベースは、モニタリングの地図とリスト、GoAccess、nginx の国別ルールで使われます。

コンテナに設定された変数は UI より優先され、そのフィールドをロックします(フィールドには「環境変数で設定済み」と表示されます)。コンテナで設定されていない項目は UI で設定してください。保存するとダウンロードがバックグラウンドで始まり、完了すると下のステータスが更新されます。

### MaxMind アカウント

無料の MaxMind アカウントとライセンスキーが必要です(MaxMind では、Account、Manage license keys)。ページにサインアップへのリンクがあります。

- **アカウント ID**: 変数 `GEOIP_ACCOUNT_ID`。
- **ライセンスキー**: 暗号化して保存され、二度と表示されません。保存済みのキーを復号できない場合は、再入力してください。変数: `GEOIP_LICENSE_KEY`。

### データベース

- **GeoLite2 Country**: 地図、国別リスト、nginx の国別ルールで使う国です。デフォルトでオンです。
- **GeoLite2 ASN**: ネットワークのリストで使うネットワーク(AS 番号と名前)です。デフォルトでオンです。
- **GeoLite2 City**: 任意で、GoAccess で使う都市です。ダウンロードがはるかに大きくなります。デフォルトでオフです。

変数: `GEOIP_EDITIONS`。スペース区切りで指定します(例: `GeoLite2-Country GeoLite2-ASN`)。データベースを 1 つも選ばない場合は、何もダウンロードも更新もされず、ダウンロード済みのデータベースは残ります。

### ステータス

最後の更新と最後のエラーを表示します。NPMpro は、アカウントやデータベースを変更したとき、**今すぐ更新**をクリックしたとき、そして 3 日ごとに自動でデータベースを更新します。自動更新に失敗した場合は、24 時間後に再試行されます。**今すぐ更新**には、保存済みのアカウント ID とライセンスキーが必要です。

データベースがない場合、地図と、国とネットワークのリストは非表示になります。それ以外は動作します。

詳しくは wiki を参照してください: Monitoring。
