## nginx

すべてのホストに適用される nginx 自体の設定です。ワーカー数、TLS のルール、オプションのモジュールを設定します。保存すると設定をテストして nginx をリロードします。テストに失敗した設定は適用されません。

コンテナに設定された変数は UI より優先され、そのフィールドをロックします(フィールドには「NGINX_WORKER_PROCESSES で設定済み」のようなロックバッジが表示されます)。コンテナで設定されていない項目は UI で設定してください。ここでの設定はすべて、保存時に実行される nginx のリロード後に適用されます。

### ワーカー

- **ワーカープロセス**: 「自動(CPU スレッドごとに 1 つ)」、またはコンテナから見える CPU スレッド数までの数値です。デフォルト: スレッドごとに 1 つ、最大 4。変数: `NGINX_WORKER_PROCESSES`。
- **ワーカーあたりの接続数**: 各ワーカーが同時に処理する開いている接続数で、64 から 65535 です。デフォルト: 512。変数: `NGINX_WORKER_CONNECTIONS`。
- **ワーカーのシャットダウンタイムアウト**: リロード後、古いワーカーが接続を保持し続ける時間です。`30s`、`10m`、`1h` のような nginx の時間値で、`0` は無制限を意味します。デフォルト: `1h`。変数: `NGINX_WORKER_SHUTDOWN_TIMEOUT`。

### ログ

- **ファイル未検出エラーをログに記録**: 存在しないファイルへのリクエストごとに、エラーログを 1 行書き込みます。デフォルト: オフ。変数: `NGINX_LOG_NOT_FOUND`。

### すべてのホストの TLS

TLS 1.2 や NIST P カーブをオフにすると、古いブラウザーやクライアントは接続できなくなります。TLS 1.3 は常にオンです。

- **TLS 1.2 を許可**: デフォルトはオンです。変数: `NGINX_DISABLE_TLS12`(反転: `true` で TLS 1.2 がオフ)。
- **耐量子鍵交換のみ**: X25519MLKEM768 のみを許可します。新しいクライアントが必要です。オンの間は TLS 1.2 と NIST P カーブがオフになり、ロックされます。デフォルト: オフ。変数: `NGINX_FORCE_X25519MLKEM768`。
- **NIST P 曲線を許可**: X25519 に加えて、鍵交換に secp521r1、secp384r1、prime256v1 を許可します。デフォルト: オン。変数: `NGINX_TRUST_SECPR1`。
- **RSA PKCS#1 署名を許可**: RSA-PSS を使えない古いクライアント向けです。デフォルト: オフ。変数: `NGINX_TRUST_RSA_PKCS1`。

### モジュール

すべてデフォルトでオフです。独自のカスタム設定が必要とする場合にだけ、モジュールをオンにしてください。カスタム設定がまだ使っているモジュールをオフにすると、nginx のテストに失敗します。

- **njs (JavaScript)**: `js_*` ディレクティブ。変数: `NGINX_LOAD_NJS_MODULE`。
- **LDAP 認証**: `auth_ldap` ディレクティブ。変数: `NGINX_LOAD_LDAP_MODULE`。
- **NTLM アップストリーム**: アップストリームブロック内の `ntlm`。変数: `NGINX_LOAD_NTLM_MODULE`。
- **仮想ホストのトラフィックステータス**: `vhost_traffic_status_*` ディレクティブ。変数: `NGINX_LOAD_VHOST_TRAFFIC_STATUS_MODULE`。

詳しくは wiki を参照してください: Configuration。
