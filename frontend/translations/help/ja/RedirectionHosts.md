## リダイレクトホストとは

リダイレクトホストは、あるドメインの訪問者を別のアドレスに送ります。サイトのドメインが変わっても古いリンクを使えるようにしたいときや、`www` をメインの名前に送りたいときに使います。

ホストのメニューにある**複製**を使うと、ホストを新しい追加ウィンドウにコピーできます。ドメインは有効なホスト 1 つにしか属せないため、コピーにはドメイン名が入りません。

### 詳細

- **ドメイン名**: リダイレクトされる名前です。必須です。新しい証明書でワイルドカードを使えるのは、DNS チャレンジの場合だけです。
- **スキーム**: 転送先のスキームです。デフォルトは「維持(リクエストと同じ)」で、訪問時の `http` または `https` をそのまま使います。`http` または `https` を選ぶこともできます。
- **転送ホスト**: 訪問者を送るドメインです(例: `example.com`)。必須です。
- **HTTP コード**: 応答コードです。デフォルトは 301 Moved permanently です。ほかに 302 Moved temporarily、303 See other、307 Temporary redirect、308 Permanent redirect を選べます。恒久的な移転には 301 または 308 を使ってください。ブラウザーや検索エンジンはこれを記憶します。
- **グループ**: 長いリストを整理するための自由なラベルです。使用中のものを選ぶか、新しい名前を入力します。
- **パスを保持**(デフォルトはオフ): 元のパスとクエリを転送先に付け加えます。オンにすると、`old.example/a?b=1` は `new.example/a?b=1` に移動します。オフの場合、訪問者はすべて転送先の先頭に着きます。

### TLS

- **TLS証明書**: なし、新しい証明書をリクエスト、または既存の証明書。以下のオプションには証明書が必要です。
- **mTLS 証明書**: クライアント証明書の認証局です。**mTLS を任意にする**と、クライアント証明書を持たない訪問者も通れます。
- **HTTPSを強制**: 最初に HTTP を HTTPS にリダイレクトします。
- **HTTP/3 サポート**: HTTP/3(QUIC)を許可します。
- **HSTS を有効化(2 年)**: HTTPS を強制が必要です。**HSTS サブドメイン + Preload** には HSTS が必要です。
- 新しい証明書の場合: **キーを再利用(非推奨)**と**DNSチャレンジを使用**があり、プロバイダー、認証情報、伝播秒数を指定します。

TLS のオプションはすべてデフォルトでオフです。

### 詳細設定

ホストの server ブロック内に追加されるカスタム nginx 設定です。変更できるのは管理者だけで、ほかのユーザーは読み取り専用で表示されます。

詳しくは wiki を参照してください: Host options。
