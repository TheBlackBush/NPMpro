## 監査ログ

誰が何を変更したかの記録です。管理者だけが見られます。

各エントリにはユーザー、オブジェクト、操作が表示されます。記録されるのは次です。

- プロキシホスト、リダイレクトホスト、404 ホスト、ストリーム、アクセスリスト、証明書、DNS 認証情報、バックアップスケジュール、ユーザー、設定の **作成**、**更新**、**削除**、**有効化**、**無効化**。
- バックアップ: スケジュールされたバックアップ実行の **バックアップ成功** と **バックアップ失敗**。
- データベースの移行: **移行済み** と **移行失敗**。

新しいエントリが先頭に並びます。**さらに読み込む** で次の 50 件が表示され、一覧の下の数字は全体のうち何件が読み込まれたかを示します。

### エントリを探す

- **検索** はすべてのエントリの詳細を対象にするため、ドメイン名やメールアドレスで該当するエントリが見つかります。
- **オブジェクトの種類**、**操作**、**ユーザー** で一覧を絞り込めます。互いに、また検索とも組み合わせられます。
- フィルターや検索が有効な間、一覧には表示中の件数が出ます。**フィルターをクリア** ですべて解除できます。

### 詳細

行の目のボタン (**詳細**) でエントリが開き、ユーザー、起きたこと、一緒に保存されたデータが表示されます。変更の場合は、保存されたときのオブジェクトです。長い値は折り返され、ウィンドウはスクロールできます。

その後に削除されたユーザーは **削除されたユーザー** と表示されます。NPMpro がエントリを自動で削除することはなく、監査ログはバックアップに含まれません。

詳しくは wiki を参照してください: Usage (Audit Logs)。
