## CrowdSec

NPMpro に組み込まれた CrowdSec bouncer を CrowdSec コンテナに接続します。ホストへのすべてのリクエストは CrowdSec Local API（LAPI）の判定に基づいて検査され、AppSec の URL を設定している場合は AppSec のルールでも検査されます。保存すると nginx の再読み込みで設定がすぐに適用され、コンテナは再起動しません。

NPMpro はこれらの設定から `/data/crowdsec/crowdsec.conf` を書き出します。このファイルを手で変更しても上書きされます。同じフォルダーの `ban.html` と `captcha.html` は自由に編集できます。

コンテナに設定した変数は UI より優先され、そのフィールドはロックされます：`CROWDSEC_ENABLED`、`CROWDSEC_LAPI_URL`、`CROWDSEC_API_KEY`、`CROWDSEC_APPSEC_URL`。

### ステータスと接続テスト

nginx が bouncer を読み込んでいるかどうかと、NPMpro が最後に LAPI に接続した時刻を表示します。**接続テスト**はフォームの値を確認します。キー（または TLS クライアント証明書）で LAPI に判定リクエストを 1 回送り、AppSec の URL がある場合は AppSec にも 1 回リクエストします。キー欄が空の場合は保存済みのキーを使います。

bouncer がオンの状態で保存すると、先に同じテストが実行されます。失敗した場合は理由が表示され、**それでも保存**を押すとそのまま保存できます。たとえば CrowdSec がまだ起動していない場合です。

AppSec が失敗し、**AppSec に接続できないとき**が**リクエストを拒否する**で、管理画面が検査対象の場合は、**それでも保存**は表示されません。その保存で管理画面から締め出されるためです。**API キー**または **AppSec の URL** を修正するか、失敗時の動作を**リクエストを通過させる**に変更するか、**管理画面を CrowdSec の対象から除外する**をオンにしてください。

### 接続

- **bouncer を有効にする**：すべてのリクエストを検査します。
- **LAPI の URL**：例：`http://127.0.0.1:8080`。
- **API キー**：`docker exec crowdsec cscli bouncers add npmpro` で取得します。暗号化して保存され、再表示されません。**保存済みのキーを削除する**で削除できます。
- **TLS クライアント証明書**：キーの代わりに、`/data/crowdsec/` 内の証明書ファイルとキーファイルを使います。`https://` の LAPI URL が必要です。
- **TLS 証明書を検証する**：https の LAPI または AppSec URL の証明書を確認します。

### ブロック

- **モード**：ライブはクライアント IP ごとに LAPI に問い合わせ、指定した秒数だけ応答をキャッシュします。ストリームは指定した間隔ですべての判定をダウンロードします。
- **BAN への応答**：BAN ページ（任意のステータスコード付き、既定は 403）、リダイレクト、またはページなしのステータスコード。
- **フォールバック対応**と**判定の種類**：bouncer が適用できない判定の扱いと、適用する種類。
- **管理画面を CrowdSec の対象から除外する**：管理画面へのリクエストは bouncer と AppSec を通りません。AppSec を拒否で使う前にオンにしておくと、CrowdSec の障害で締め出されることがありません。

### キャプチャ

プロバイダー（reCAPTCHA、hCaptcha、Cloudflare Turnstile）、そのサイトキーとシークレットキー、解決済みキャプチャの有効期間。種類がキャプチャの判定に使われます。

### AppSec

- **AppSec の URL**：例：`http://127.0.0.1:7422`。空にすると AppSec は無効になります。
- **AppSec に接続できないとき**：AppSec が停止している間、拒否は検査対象のすべてのリクエストをブロックします。通過させると、検査せずにそのまま通します。

### 詳細設定

LAPI リクエストのタイムアウト、シナリオのフィルター、除外するパス、内部リクエスト、AppSec のタイムアウトとオプション、BAN ページとキャプチャページのファイル（**プレビュー**付き）。

### 締め出された場合

CrowdSec を再び起動するか、コンテナに `CROWDSEC_ENABLED=false` を設定して再作成してください。そのあと、ここで設定を修正します。

詳しくは wiki を参照してください: CrowdSec。
