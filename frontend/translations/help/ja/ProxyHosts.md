## プロキシホストとは

プロキシホストは、Web サービスの玄関口です。訪問者は NPMpro 上のドメインを開き、NPMpro がそのリクエストを背後のサービスに転送します。TLS(HTTPS)を持たないサービスに TLS を追加することもできます。プロキシホストは NPMpro で最も一般的な使い方です。

ホストのメニューにある**複製**を使うと、ホストを新しい追加ウィンドウにコピーできます。ドメインは有効なホスト 1 つにしか属せないため、コピーにはドメイン名が入りません。

### 詳細

- **ドメイン名**: 訪問者が使う名前です。必須です。新しい証明書の場合、ワイルドカード(`*.example.com`)には DNS チャレンジが必要です。
- **スキーム**: NPMpro がサービスと通信する方法です。`http://`、`https://`、`grpc://`、`grpcs://`、`path`(フォルダからファイルや PHP を提供)、`empty`(アップストリームなし)から選びます。デフォルトは `http://` です。スキームを変更すると、合わなくなったオプションはオフになります。
- **転送先ホスト名 / IP / パス**: サービスのアドレスです。`127.0.0.1/path` のようにサブパスを付けられます。`path` では代わりにフォルダを入力します。ファイルは `/var/www` の下にマウントしてください。それ以外の場所のフォルダは管理者だけが使えます。`cu_` で始まる名前は、独自の nginx アップストリームブロックを指します(wiki の Load balancing を参照)。
- **転送ポート**: 任意です。`path` では PHP のバージョンになります。
- **グループ**: 長いリストを整理するための自由なラベルです。
- **オプション**(すべてデフォルトはオフ):
  - **noindex ヘッダーを送信し、一部のボットのユーザーエージェントをブロック**: 検索エンジンにサイトをインデックスしないよう依頼し、一部のクローラーをブロックします。
  - **CrowdSec AppSec を無効化**: このホストだけ CrowdSec AppSec をオフにします。AppSec が設定されている場合にのみ効果があります。
  - **リクエストバッファリングを無効化**と**レスポンスバッファリングを無効化**: http と https のアップストリーム用です。高速で安定した回線でストリーミングや大きなファイルのアップロードを行う場合を除き、バッファリングはオンのままにしてください。リクエストバッファリングをオフにすると AppSec もオフになります。
  - **アップストリームによる圧縮を有効化**: サービスが自身の応答を圧縮できるようにします。サービスが必要としない限りオフのままにしてください。`path` と `empty` では使えません。
  - **fancyindex を有効化**: フォルダにインデックスファイルがない場合にファイル一覧を表示します。`path` でのみ使えます。
- **X-Frame-Options**: `SAMEORIGIN`(デフォルト)、`DENY`、`none`(ヘッダーを削除)、`upstream`(サービスが送る値をそのまま保持)。
- **Auth Request**: ホストの前にログインやボットチェックを置きます(Anubis、Tinyauth、OAuth2 Proxy、VoidAuth、Authelia、Authentik)。デフォルトは `none` です。**Auth Request アップストリーム**は任意です。空の場合は、設定の「フォワード認証」のデフォルトが使われます。
- **グローバルアクセスリスト**: **公開されたアクセス**(デフォルト、ログインなし)または**カスタム**(1 つ以上のアクセスリスト)。

WebSocket は常にオンです。

### カスタムロケーション

ロケーションは、ホストの 1 つのパス(たとえば `/api/`)を別のサービスに送ります。それぞれに**有効化**、パスと任意の一致タイプ(`=`、`~`、`~*`、`^~`、`@`)、独自のスキーム、ホスト、ポート、オプション、Auth Request、アクセスリストがあります。アクセスリストには**グローバル**を選べます。この場合はホストのリストを使います。ホストの Auth Request は引き継がれません。前方一致にしたい場合を除き、パスの末尾にスラッシュを付けてください。管理者は歯車ボタンから、ロケーションごとにカスタム nginx 設定を追加できます。

### TLS

- **TLS証明書**: なし、新しい証明書をリクエスト、または既存の証明書。以下のオプションには証明書が必要です。
- **mTLS 証明書**: クライアント証明書の認証局です。**mTLS を任意にする**と、証明書を持たない訪問者も通れます。**mTLS で Auth Request をバイパス**を使うと、有効な証明書を持つ訪問者は Auth Request を省略できます。
- **HTTPSを強制**は HTTP を HTTPS にリダイレクトします。**HTTP/3 サポート**は HTTP/3(QUIC)を許可します。
- **HSTS を有効化(2 年)**: HTTPS を強制が必要です。**HSTS サブドメイン + Preload** には HSTS が必要です。
- 新しい証明書の場合: **キーを再利用(非推奨)**と**DNSチャレンジを使用**があり、プロバイダー、認証情報、伝播秒数を指定します。

### 詳細設定

ホスト全体(server ブロック)とメインロケーション `location /` のカスタム nginx 設定です。変更できるのは管理者だけです。

詳しくは wiki を参照してください: Host options。
