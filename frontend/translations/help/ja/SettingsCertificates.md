## 証明書と TLS

ACME サーバー(`ACME_SERVER` で別のサーバーを指定しない限り Let's Encrypt)にリクエストする証明書のデフォルト、ステープリングと更新の方法、不明なホストにどの証明書で応答するかを設定します。これは設定のセクションであり、証明書の一覧ページではありません。

コンテナに設定された変数は UI より優先され、そのフィールドをロックします(フィールドには「ACME_KEY_TYPE で設定済み」のようなロックバッジが表示されます)。一部のフィールドは他のフィールドに連動します。ECDSA カーブを指定した `ACME_KEY_SIZE` だけが設定されている場合、鍵タイプは ECDSA のままになり、Must-Staple は OCSP ステープリングをオンに保ちます。コンテナで設定されていない項目は UI で設定してください。

### 証明書リクエスト

これらは次の証明書リクエストから適用されます。

- **鍵タイプ**: `ECDSA`(デフォルト、推奨: 鍵が小さく、ハンドシェイクが速い)、または ECDSA を使えないクライアント向けの `RSA`。変数: `ACME_KEY_TYPE`。
- **鍵サイズ**: ECDSA ではカーブ(`secp256r1`、`secp384r1`、`secp521r1`、デフォルトは `secp384r1`)、RSA ではビット数(`2048`、`3072`、`4096`、デフォルトは `4096`)。変数: `ACME_KEY_SIZE`。
- **ACME プロファイル**: サーバーにリクエストするプロファイルです。保存時にサーバーで確認されます。空の場合はサーバーのデフォルトを使います。Let's Encrypt のデフォルトは `shortlived` です。Common Name を必要とするクライアントは、`shortlived` と `tlsserver` の証明書では動作しません。変数: `ACME_PROFILE`(空にするには `none`)。
- **OCSP Must-Staple**: 新しい証明書に must-staple を付け、OCSP ステープリングをオンに保ちます。対応している CA(ZeroSSL)でのみ使えます。Let's Encrypt はこうしたリクエストを拒否します。デフォルト: Google Trust Services と ZeroSSL ではオン、それ以外はオフ。変数: `ACME_MUST_STAPLE`。
- **ACME サーバーの証明書を検証**: デフォルトはオンです。自己署名証明書を使うプライベート ACME サーバーの場合にのみオフにしてください。変数: `ACME_SERVER_TLS_VERIFY`。

### ステープリング

どちらも、保存時に実行される nginx のリロード後に適用され、どちらも TLS 証明書の圧縮をオフにします。

- **ACME 証明書の OCSP ステープリング**: CA が OCSP を提供している場合に、ACME サーバーの証明書とともに OCSP 応答を送ります。デフォルト: Google Trust Services と ZeroSSL ではオン、それ以外はオフ。変数: `ACME_OCSP_STAPLING`。
- **カスタム証明書の OCSP ステープリング**: アップロードした証明書に対する同じ設定です。デフォルト: オフ。変数: `CUSTOM_OCSP_STAPLING`。

### デフォルト証明書

- **不明なホストと Web UI の証明書**: NPMpro にホストがないホスト名と、Web UI のポートで提供されます。デフォルト: 組み込み(生成されたプレースホルダー)。変数: `DEFAULT_CERT_ID`(証明書 ID。`0` は組み込み)。保存時に実行される nginx のリロード後に適用されます。

### 更新

- **更新チェックの間隔**: チェックの間隔で、1 から 499 時間です。証明書は、期限が来たときだけ更新されます。デフォルト: 3。変数: `CERTBOT_RUN_INTERVAL`。すぐに適用されます。

### ECH

- **ECH キーのローテーション間隔**: ECH スクリプト(`/data/tls/ech/cron.sh`)の実行間隔で、1 から 24 時間です。スクリプトが空でない場合にのみ使われます。デフォルト: 1。変数: `ECH_ROTATION_INTERVAL`。すぐに適用されます。
