## 認証

OIDC プロバイダー(たとえば Authentik、Keycloak、Google)で NPMpro の Web UI にサインインします。パスワードと併用することも、パスワードの代わりにすることもできます。これはフォワード認証ではありません。プロキシホストを保護するものではありません。それについては、設定の「フォワード認証」を参照してください。

コンテナに設定された変数は UI より優先され、そのフィールドをロックします(フィールドには「環境変数で設定済み」と表示されます)。4 つの接続用変数がすべて設定されている場合、UI で有効にしなくても OIDC は有効です。コンテナで設定されていない項目は UI で設定してください。ここでの設定はすべて、保存したときに適用されます。

### プロバイダー

- **OIDC サインインを有効化**: ログインページにサインインボタンを表示します。
- **発行者 URL**: プロバイダーのディスカバリーのベースアドレスです(例: `https://accounts.example.com`)。変数: `OIDC_ISSUER_URL`。
- **クライアント ID**と**クライアントシークレット**: プロバイダーから取得します。シークレットは暗号化して保存され、二度と表示されません。そのままにするには空欄にします。発行者 URL またはクライアント ID を変更した場合は、シークレットを再入力してください。変数: `OIDC_CLIENT_ID`、`OIDC_CLIENT_SECRET`。
- **リダイレクトドメイン**: NPMpro を開くのに使うドメインです。ポートが 443 でない場合はポートも付けます。コールバック URL の生成に使うため必須です。変数: `OIDC_REDIRECT_DOMAIN`。
- **コールバック URL**: 読み取り専用です。プロバイダーにリダイレクト URI として登録してください。
- **スコープ**: デフォルトは `openid email profile` です。プロバイダーが一部しか許可しない場合は変更してください(例: `openid email`)。
- **接続テスト**: NPMpro が発行者に接続できるかを確認します。

### ログインボタン

サインインページのボタンです。**表示名**(「でサインイン」の前に表示される文字)、**色**(プリセットまたは独自の `#rrggbb`)、**アイコン**(組み込み、PNG、JPEG、WebP、SVG の 256 KB までのアップロード、または URL からのダウンロード)を設定します。プレビューが表示されます。

### サインインのルール

- **確認済みのメールアドレスを必須にする**: プロバイダーがメールアドレスを確認していないユーザーを拒否します。デフォルト: オン。変数: `OIDC_REQUIRE_VERIFIED_EMAIL`。
- **OIDC 後の二要素認証をスキップ**: プロバイダー自身の多要素認証チェックを信頼します。デフォルト: オフ。変数: `OIDC_SKIP_MFA`。
- **パスワードログインを無効化**: OIDC だけでサインインできるようになります。オンにできるのは、OIDC でサインインしたセッションからだけです。変数: `OIDC_DISABLE_PASSWORD`。パスワードログインを元に戻すには、これを `false` にしてコンテナを作り直します。

### 新規ユーザー

- **初回サインイン時にユーザーを作成**(デフォルト: オフ): アカウントを持たない人に、下の権限でアカウントが作成されます。
- **許可するメールドメイン**: カンマ区切りです。空の場合はすべてのドメインを許可します。リストが空で、確認済みのメールアドレスも必須でない場合、プロバイダーが受け入れた人は誰でもアカウントを得られます。
- **新規ユーザーのデフォルト権限**: セクションごとに設定します。新規ユーザーが管理者になることはありません。

詳しくは wiki を参照してください: Authentication。
