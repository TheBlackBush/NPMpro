## ネットワーク

NPMpro の前段にあるプロキシのうち、実際のクライアントアドレスを信頼できるものを NPMpro に伝えます。これがないと、ログ、アクセスリスト、CrowdSec には、訪問者ではなくプロキシのアドレスが見えます。

コンテナに設定された変数は UI より優先され、そのフィールドをロックします(フィールドには「TRUST_IP で設定済み」のようなロックバッジが表示されます)。コンテナで設定されていない項目は UI で設定してください。

- **信頼するプロキシ IP**: 1 行に 1 つの IPv4 または IPv6 アドレス、または CIDR 範囲です(例: `10.0.0.0/8`、`192.168.1.5`、`fd00::/8`)。これらのアドレスからのリクエストは、実際のクライアント IP を `X-Forwarded-For` で渡せます。NPMpro の直前にあるロードバランサーやトンネルに使います。デフォルト: 空(誰も信頼しません)。変数: `TRUST_IP`(スペース区切り)。保存時に実行される nginx のリロード後に適用されます。
- **Cloudflare を信頼**: Cloudflare の IP 範囲を取得して定期的に更新し、それを信頼するため、nginx は Cloudflare の背後にいる実際のクライアント IP を認識できます。デフォルト: オフ。変数: `TRUST_CLOUDFLARE`。保存時に実行される nginx のリロード後に適用されます。先に wiki の Cloudflare に関する注意(Security)を読んでください。NPMpro の前に Cloudflare を置くと、プライバシーとセキュリティ上のコストがかかります。

自分で管理しているアドレス、または完全に信頼できるアドレスだけを信頼してください。信頼されたアドレスは、どんな訪問者を名乗ることもできます。

保存時に nginx のテストに失敗した場合は、何も保存されず、nginx のメッセージが表示されます。

詳しくは wiki を参照してください: Security。
