## ダイナミック DNS

NPMpro が「ダイナミック DNS」タブ（証明書）のレコードをパブリックアドレスに向け続ける仕組みです。レコードを有効にするまで何も確認されません。

コンテナに設定した変数は UI より優先され、フィールドをロックします（フィールドには「DDNS_PERIOD で設定済み」のような鍵アイコンのバッジが表示されます）。コンテナで設定していない項目は UI で設定してください。

- **確認間隔**: レコードを確認する頻度。`1m` から `24h` まで（例: `5m`、`1h30m`）。既定値: `5m`。変数: `DDNS_PERIOD`。変更するとタイマーが再起動します。
- **クールダウン**: 1 つのレコードの 2 回の書き込みの最短間隔。形式は同じです。既定値: `5m`。変数: `DDNS_COOLDOWN`。
- **IPv4 アドレスサービス**と **IPv6 アドレスサービス**: パブリックアドレスを返す 2 から 10 個の `https://` URL。新しいアドレスは 2 つ目のサービスが確認した場合のみ書き込まれ、変わらないアドレスは 1 つのサービスで受け入れられます。IPv6 サービスは、有効なレコードが IPv6 を必要とする間だけ問い合わせます。変数: `DDNS_IPV4_SERVICES`、`DDNS_IPV6_SERVICES`（スペース区切り）。このホスト、リンクローカルアドレス（クラウドのメタデータなど）、マルチキャストまたは予約済みアドレス上のサービスは拒否されます。プライベート LAN のアドレスは使えます。
- **確認用の DNS サーバー**: プロバイダーに問い合わせる前のレコード名の名前解決（スプリットホライズン）にのみ使います。アドレスサービスとプロバイダーは常にコンテナのリゾルバーを使います。空の場合はここでもコンテナのリゾルバーを使います。IPv4 アドレス、または角括弧で囲んだ IPv6 アドレス（ポートは任意）。変数: `DDNS_RESOLVER`（スペース区切り）。

レコードは「ダイナミック DNS」タブで、レコードを更新できるプロバイダーの DNS 認証情報を使って追加します。
