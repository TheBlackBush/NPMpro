## デフォルトサイト

デフォルトサイトは、どのホストも使っていないホスト名や、サーバーの IP アドレスで訪問者が NPMpro にアクセスしたときに、nginx が返す応答です。ここで応答を選びます。不明なすべての名前に適用されます。

保存すると、まず新しい選択が nginx でテストされます。テストに失敗した場合は何も保存されず、以前のデフォルトサイトが維持され、nginx のエラーはコンテナのログに記録されます。

- **お祝いページ**(デフォルト): NPMpro のウェルカムページを表示します。
- **404ページ**: 404 Not Found ページで応答します。
- **返答しない (444)**: 何も応答せずに接続を閉じます。スキャナーに何も見せたくないときに使います。不明な名前への HTTPS リクエストは、TLS ハンドシェイクの時点で拒否されます。
- **リダイレクト**: 一時的なリダイレクト(302)で訪問者を別のアドレスに送ります。スペース、引用符、`; { } #` を含まない、`http://` または `https://` で始まる完全な URL を 255 文字以内で入力します。
- **カスタムHTML**: 独自の HTML ページを表示します。その下の **HTTP ステータスコード**は任意で、400 から 599 です。空の場合は 200 (OK) です。

返答しない以外のすべての選択では、不明な名前への通常の HTTP リクエストはまず HTTPS にリダイレクトされ、HTTPS リクエストには設定の「証明書と TLS」で**デフォルト証明書**として選んだ証明書が使われます。

このセクションには環境変数がないため、変更は保存したときに適用されます。
