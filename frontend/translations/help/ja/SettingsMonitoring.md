## ログとモニタリング

ログファイル、GoAccess ログレポート、モニタリングページの元になるトラフィック統計です。

コンテナに設定された変数は UI より優先され、そのフィールドをロックします(フィールドには「LOGROTATE で設定済み」のようなロックバッジが表示されます。統計では「環境変数で設定済み」と表示されます)。コンテナで設定されていない項目は UI で設定してください。「再起動が必要」と表示された設定は、すぐに保存されますが、コンテナの起動時に読み込まれます。その場合、このセクションの「適用するにはコンテナを再起動してください」に表示されます。

### ログファイル

- **ログファイルを書き込む**: nginx のエラー、ストリーム、アクセスログを `/data/nginx/logs` に書き込み、毎日ローテーションします。デフォルト: オフ。変数: `LOGROTATE`。保存時に実行される nginx のリロード後に適用されます。GoAccess が動作している間はオンのままです。
- **保持するログローテーション数**: 最も古いものが削除されるまでに、ローテーションしたログファイルをいくつ残すかです。1 から 1000。デフォルト: 3。変数: `LOGROTATIONS`。すぐに適用されます。

### GoAccess

- **GoAccess レポート**: 管理者向けの Web ログレポートである GoAccess を、Web UI の `/goaccess` で実行します。デフォルト: オフ。変数: `GOA`。コンテナの再起動後に適用されます。トラフィック統計はオンになりません。

レポートをオンにすると、次のオプションが表示されます。すべてコンテナの再起動後に適用されます。1 つの変数 `GOACLA` で、これらすべてを独自の GoAccess オプションに置き換え、これらをロックできます。

- **レポートデータの保持期間**: 1 から 366 日。デフォルト: 30。
- **訪問者 IP を匿名化**: オフ、レベル 1(デフォルト)、レベル 2(強)、レベル 3(厳格)。レベル 1 は IPv4 の最後の 1 バイト(IPv6 は最後の 64 ビット)、レベル 2 は 2 バイト(80 ビット)、レベル 3 は 3 バイト(96 ビット)を隠します。
- **クエリ文字列を除去**: レポート内の URL からクエリ文字列を取り除くため、URL 内のトークンは保存されません。デフォルト: オン。
- **OS の完全なバージョン**: ファミリーだけでなく、完全なバージョンを表示します。デフォルト: オン。
- **ホスト名を解決**: 訪問者 IP のホスト名を調べます。そのために DNS クエリを送信します。デフォルト: オン。

### モニタリング

モニタリングページのトラフィックタブを制御します。すべて保存するとすぐに適用されます。変数: `TRAFFIC_STATS`、`TRAFFIC_RETENTION_DAYS`、`TRAFFIC_SHOW_IPS`、`TRAFFIC_UNIQUE_VISITORS`、`TRAFFIC_VISITORS_CAP`。

- **トラフィック統計**: nginx のアクセスログを読み込み、ホスト、ステータス、国、ネットワークごとにリクエストを集計します。デフォルト: オフ。オフにすると新しい集計は止まります。保存済みの統計は、ダイアログで「保存済みの統計も削除」にチェックを入れない限り、期限が切れるまで残ります。
- **統計の保持期間**: 7 から 365 日。デフォルト: 30。分単位のデータは 24 時間、時間単位のデータはこの日数だけ保持されます。
- **訪問者 IP を表示**: 上位の IP を一覧表示するため、訪問者 IP を 1 時間ごとに保存します。デフォルト: プライバシーのためオフ。オフにすると、保存済みの IP は削除されます。
- **ユニークビジターを集計**: ユニークビジターを数えるため、ホストと日ごとに、各訪問者 IP のキー付きハッシュを保存します。デフォルト: オフ。オフにすると、ハッシュは削除されます。
- **ホストと日ごとの訪問者上限**: 1000 から 1000000。デフォルト: 100000。上限に達したホストは、その日は新しい訪問者の集計を止め、プラス記号を表示します。

国とネットワークには GeoIP データベースが必要です(設定、GeoIP)。
