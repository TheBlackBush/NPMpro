## Страница по умолчанию

Страница по умолчанию это то, что nginx отвечает, когда посетитель приходит в NPMpro с именем хоста, которое не использует ни один хост, или по IP-адресу сервера. Здесь вы выбираете этот ответ. Он применяется ко всем неизвестным именам.

При сохранении nginx сначала проверяет новый выбор. Если проверка не пройдена, ничего не сохраняется, прежняя страница по умолчанию остаётся, а ошибка nginx записывается в журнал контейнера.

- **Страница поздравления** (по умолчанию): показывает приветственную страницу NPMpro.
- **404-страница**: отвечает страницей 404 Not Found.
- **Нет ответа (444)**: закрывает соединение без какого-либо ответа. Используйте, чтобы сканерам нечего было увидеть. HTTPS-запросы к неизвестным именам отклоняются во время TLS-рукопожатия.
- **Перенаправление**: отправляет посетителей на другой адрес временным перенаправлением (302). Введите полный URL `http://` или `https://` без пробелов, кавычек и символов `; { } #`, не длиннее 255 символов.
- **Свой HTML**: показывает вашу HTML-страницу. **HTTP-код ответа** под ней необязателен, от 400 до 599. Оставьте пустым для 200 (OK).

Для любого варианта, кроме «Нет ответа», запросы к неизвестным именам по обычному HTTP сначала перенаправляются на HTTPS, а HTTPS-запросы используют сертификат, выбранный как **Сертификат по умолчанию** в разделе Настройки, Сертификаты и TLS.

В этом разделе нет переменных окружения, поэтому изменение применяется при сохранении.
