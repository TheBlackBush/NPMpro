## Что такое хост перенаправления?

Хост перенаправления отправляет посетителей одного домена на другой адрес. Используйте его, когда сайт меняет домен и старые ссылки должны продолжать работать, или чтобы отправить `www` на основное имя.

Используйте **Клонировать** в меню хоста, чтобы скопировать хост в новое окно добавления. Копия создаётся без доменных имён, потому что домен может принадлежать только одному включённому хосту.

### Сведения

- **Домены**: имена, которые перенаправляются. Обязательное поле. Подстановочные имена для нового сертификата разрешены только при проверке через DNS.
- **Схема**: схема цели. По умолчанию «сохранить (как в запросе)» (как в запросе), то есть сохраняется `http` или `https` из запроса. Либо выберите `http` или `https`.
- **Целевой домен**: домен, на который отправляются посетители, например `example.com`. Обязательное поле.
- **HTTP-код**: код ответа. По умолчанию 301 Moved permanently. Другие варианты: 302 Moved temporarily, 303 See other, 307 Temporary redirect и 308 Permanent redirect. Используйте 301 или 308, если переезд окончательный; браузеры и поисковые системы их запоминают.
- **Группа**: произвольная метка, которая помогает держать длинные списки в порядке. Выберите используемую или введите новое имя.
- **Сохранять путь** (по умолчанию выключено): добавляет к цели исходный путь и запрос. Если включено, `old.example/a?b=1` ведёт на `new.example/a?b=1`. Если выключено, все посетители попадают в начало цели.

### TLS

- **TLS-сертификат**: Нет, запросить новый сертификат или существующий. Параметры ниже требуют сертификата.
- **Сертификат mTLS**: центр сертификации клиентских сертификатов. **Сделать mTLS необязательным** пропускает посетителей без клиентского сертификата.
- **Всегда HTTPS**: сначала перенаправляет HTTP на HTTPS.
- **Поддержка HTTP/3**: включает HTTP/3 (QUIC).
- **HSTS включён (2 года)**: требует «Всегда HTTPS». **HSTS для поддоменов + Preload** требует HSTS.
- Для нового сертификата: **Повторно использовать ключ (не рекомендуется)** и **Проверка через DNS**, с провайдером, учётными данными и временем распространения в секундах.

Все параметры TLS по умолчанию выключены.

### Расширенные

Собственная конфигурация nginx, добавляемая внутрь блока server хоста. Изменять её могут только администраторы; остальные пользователи видят её только для чтения.
