## Журналы и мониторинг

Файлы журналов, отчёт GoAccess по журналам и статистика трафика, на которой основана страница мониторинга.

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показан значок блокировки, например «Задано LOGROTATE», или «Задано окружением» для статистики). Всё, что не задано в контейнере, настраивайте в интерфейсе. Настройки с пометкой «Требуется перезапуск» сохраняются сразу, но читаются при запуске контейнера; затем раздел показывает их в списке «Перезапустите контейнер, чтобы применить».

### Файлы журналов

- **Записывать файлы журналов**: записывает журналы ошибок, потоков и доступа nginx в `/data/nginx/logs` и ротирует их ежедневно. По умолчанию: выключено. Переменная: `LOGROTATE`. Применяется после перезагрузки nginx, которую выполняет сохранение. Остаётся включённым, пока работает GoAccess.
- **Хранимые ротации журналов**: сколько ротированных файлов журналов хранится, прежде чем самый старый удаляется, от 1 до 1000. По умолчанию: 3. Переменная: `LOGROTATIONS`. Применяется сразу.

### GoAccess

- **Отчёт GoAccess**: запускает GoAccess, отчёт по веб-журналам для администраторов, по адресу `/goaccess` веб-интерфейса. По умолчанию: выключено. Переменная: `GOA`. Применяется после перезапуска контейнера. Статистику трафика он не включает.

Когда отчёт включён, показываются эти параметры. Все применяются после перезапуска контейнера. Одна переменная, `GOACLA`, заменяет их все вашими собственными параметрами GoAccess и блокирует их.

- **Хранить данные отчёта**: от 1 до 366 дней. По умолчанию: 30.
- **Анонимизировать IP посетителей**: Выкл., Уровень 1 (по умолчанию), Уровень 2 (сильная) или Уровень 3 (педантичная). Уровень 1 скрывает последний байт IPv4 (последние 64 бита IPv6), уровень 2 два байта (80 бит), уровень 3 три байта (96 бит).
- **Отбрасывать строки запроса**: убирает строки запроса из URL в отчёте, чтобы токены в URL не сохранялись. По умолчанию: включено.
- **Полные версии операционных систем**: показывает полную версию, а не только семейство. По умолчанию: включено.
- **Определять имена хостов**: определяет имена хостов по IP посетителей. При этом отправляются DNS-запросы. По умолчанию: включено.

### Мониторинг

Управляют вкладкой «Трафик» страницы мониторинга. Все применяются сразу при сохранении. Переменные: `TRAFFIC_STATS`, `TRAFFIC_RETENTION_DAYS`, `TRAFFIC_SHOW_IPS`, `TRAFFIC_UNIQUE_VISITORS`, `TRAFFIC_VISITORS_CAP`.

- **Статистика трафика**: читает журнал доступа nginx и считает запросы по хосту, статусу, стране и сети. По умолчанию: выключено. Выключение прекращает новый подсчёт; сохранённая статистика остаётся, пока не устареет, если только вы не отметите «Также удалить сохранённую статистику» в диалоге.
- **Хранить статистику**: от 7 до 365 дней. По умолчанию: 30. Данные по минутам хранятся 24 часа, данные по часам столько дней.
- **Показывать IP посетителей**: сохраняет IP посетителей по часам, чтобы показывать список самых частых IP. По умолчанию: выключено, ради приватности. Выключение удаляет сохранённые IP.
- **Считать уникальных посетителей**: сохраняет хэш с ключом от IP каждого посетителя по хосту и дню, чтобы считать уникальных посетителей. По умолчанию: выключено. Выключение удаляет хэши.
- **Лимит посетителей на хост в день**: от 1000 до 1000000. По умолчанию: 100000. Хост, достигший его, в этот день перестаёт считать новых посетителей и показывает знак плюс.

Страны и сети требуют баз данных GeoIP (Настройки, GeoIP).
