## GeoIP

NPMpro сам скачивает бесплатные базы данных MaxMind GeoLite2 и определяет страны и сети на вашем сервере, поэтому IP-адреса посетителей никуда не отправляются. Отдельный контейнер geoipupdate не нужен. Базы данных используются на карте и в списках мониторинга, в GoAccess и в правилах nginx по странам.

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показано «Задано окружением»). Всё, что не задано в контейнере, настраивайте в интерфейсе. Сохранение запускает скачивание в фоне, а статус ниже обновляется, когда оно завершено.

### Учётная запись MaxMind

Вам нужны бесплатная учётная запись MaxMind и лицензионный ключ (в MaxMind: Account, Manage license keys). На странице есть ссылка для регистрации.

- **ID учётной записи**: переменная `GEOIP_ACCOUNT_ID`.
- **Лицензионный ключ**: хранится в зашифрованном виде и больше не показывается. Если сохранённый ключ не удаётся расшифровать, введите его снова. Переменная: `GEOIP_LICENSE_KEY`.

### Базы данных

- **GeoLite2 Country**: страны для карты, списков стран и правил nginx по странам. По умолчанию включено.
- **GeoLite2 ASN**: сети (номер и имя AS) для списков сетей. По умолчанию включено.
- **GeoLite2 City**: необязательно, города для GoAccess. Намного больший объём загрузки. По умолчанию выключено.

Переменная: `GEOIP_EDITIONS`, через пробел, например `GeoLite2-Country GeoLite2-ASN`. Если не выбрана ни одна база данных, ничего не скачивается и не обновляется, а уже скачанные базы остаются.

### Статус

Показывает последнее обновление и последнюю ошибку. NPMpro обновляет базы данных при смене учётной записи или баз данных, при нажатии **Обновить сейчас** и автоматически каждые 3 дня. Неудачное автоматическое обновление повторяется через 24 часа. Для **Обновить сейчас** нужны сохранённые ID учётной записи и лицензионный ключ.

Без баз данных карта и списки стран и сетей скрыты; остальное работает.
