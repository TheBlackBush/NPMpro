## Доступ к API

Все API-токены всех пользователей. Эту страницу видят только администраторы.

Токены создают их владельцы в меню пользователя, в разделе **API-токены**. Здесь виден каждый токен с владельцем, правами, сроком действия, временем последнего использования и датой создания.

- **Отозвать** останавливает токен сразу. Скрипты и ИИ-ассистенты, которые его используют, после этого получают ошибку аутентификации.
- У токена никогда не бывает больше прав, чем у его владельца. Токен администратора действует как администратор только при включенном переключателе **Администратор**, и ни один токен не управляет пользователями.
- Создание, отзыв, истечение срока и первое использование токена записываются в журнал аудита, имя токена показано рядом с пользователем.

**Документация API** открывает в новой вкладке справочник API по каждой конечной точке и показывает заголовок, в котором передаётся токен. **Сервер MCP** показывает конечную точку, настройку для Claude Code, для Claude Desktop и других клиентов, а также инструменты, доступные токену.
