## Аутентификация

Вход в веб-интерфейс NPMpro через провайдера OIDC (например, Authentik, Keycloak или Google) наряду с паролями или вместо них. Это не внешняя аутентификация: она не защищает ваши прокси-хосты. Для этого см. Настройки, Внешняя аутентификация.

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показано «Задано окружением»). Если заданы все четыре переменные подключения, OIDC работает без включения в интерфейсе. Всё, что не задано в контейнере, настраивайте в интерфейсе. Всё здесь применяется при сохранении.

### Провайдер

- **Включить вход через OIDC**: показывает кнопку входа на странице входа.
- **URL издателя**: базовый адрес обнаружения (discovery) провайдера, например `https://accounts.example.com`. Переменная: `OIDC_ISSUER_URL`.
- **ID клиента** и **Секрет клиента**: выдаются вашим провайдером. Секрет хранится в зашифрованном виде и больше не показывается; оставьте поле пустым, чтобы сохранить его. Если вы меняете URL издателя или ID клиента, введите секрет снова. Переменные: `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`.
- **Домен перенаправления**: домен, по которому открывают NPMpro, с портом, если он не 443. Обязательное поле, потому что из него строится URL обратного вызова. Переменная: `OIDC_REDIRECT_DOMAIN`.
- **URL обратного вызова**: только для чтения. Зарегистрируйте его у провайдера как redirect URI.
- **Области (scopes)**: по умолчанию `openid email profile`. Измените, если провайдер разрешает только некоторые, например `openid email`.
- **Проверить подключение**: проверяет, что NPMpro может связаться с издателем.

### Кнопка входа

Кнопка на странице входа: **Отображаемое имя** (текст после «Войти через»), **Цвет** (готовый вариант или ваш `#rrggbb`) и **Значок** (встроенный, загруженный как PNG, JPEG, WebP или SVG размером до 256 КБ либо скачанный по URL). Показывается предпросмотр.

### Правила входа

- **Требовать подтверждённый адрес эл. почты**: отклоняет пользователей, чей адрес эл. почты провайдер не подтвердил. По умолчанию: включено. Переменная: `OIDC_REQUIRE_VERIFIED_EMAIL`.
- **Пропускать двухфакторную проверку после OIDC**: доверяет собственной многофакторной проверке провайдера. По умолчанию: выключено. Переменная: `OIDC_SKIP_MFA`.
- **Отключить вход по паролю**: войти можно только через OIDC. Включить это можно только из сеанса, в который вы вошли через OIDC. Переменная: `OIDC_DISABLE_PASSWORD`; чтобы вернуть вход по паролю, задайте `false` и пересоздайте контейнер.

### Новые пользователи

- **Создавать пользователей при первом входе** (по умолчанию: выключено): человек без учётной записи получает её с разрешениями ниже.
- **Разрешённые почтовые домены**: через запятую; пустое поле разрешает любой домен. Если список пуст и подтверждённый адрес эл. почты не требуется, учётную запись получает любой, кого принимает ваш провайдер.
- **Разрешения по умолчанию для новых пользователей**: задаются для каждого раздела. Новые пользователи никогда не бывают администраторами.
