## Внешняя аутентификация

Внешняя аутентификация ставит перед прокси-хостом проверку входа или ботов. Для каждого запроса nginx сначала спрашивает у сервиса аутентификации, может ли посетитель пройти. В NPMpro это встроено для Anubis, Tinyauth, OAuth2 Proxy, VoidAuth, Authelia и Authentik. Провайдера вы запускаете в отдельном контейнере.

На этой странице задаётся адрес по умолчанию (upstream) каждого провайдера. В прокси-хосте проверка включается через **Auth Request** в разделе «Параметры» на вкладке «Сведения» (или в собственном маршруте).

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показан значок блокировки, например «Задано AUTH_REQUEST_AUTHELIA_UPSTREAM»). Всё, что не задано в контейнере, настраивайте в интерфейсе. Каждая настройка здесь применяется после перезагрузки nginx, которую выполняет сохранение. Если проверка nginx не пройдена, ничего не сохраняется.

### Upstream по умолчанию

- **Upstream Anubis**, **Upstream Tinyauth**, **Upstream OAuth2 Proxy**, **Upstream VoidAuth**, **Upstream Authelia**, **Upstream Authentik**: используются прокси-хостами с этим провайдером, у которых нет собственного upstream. Собственное значение хоста главнее. По умолчанию: пусто (нет). Переменные: `AUTH_REQUEST_ANUBIS_UPSTREAM`, `AUTH_REQUEST_TINYAUTH_UPSTREAM`, `AUTH_REQUEST_OAUTH2PROXY_UPSTREAM`, `AUTH_REQUEST_VOIDAUTH_UPSTREAM`, `AUTH_REQUEST_AUTHELIA_UPSTREAM`, `AUTH_REQUEST_AUTHENTIK_UPSTREAM`.

Формат: `scheme://host:port`, например `http://127.0.0.1:9091`, или `scheme://cu_name` для вашего собственного блока upstream в nginx, имя которого начинается с `cu_`. Используйте `http` или `https`; порт обязателен; адрес IPv6 пишется в квадратных скобках. Без пути, без пробелов и без символов `; { } # " ' $ \`.

Нельзя очистить значение по умолчанию, пока прокси-хосты используют этого провайдера без собственного upstream. В сообщении перечислены эти хосты.

Хост, который использует провайдера без upstream где-либо, получает «Ошибка конфигурации».

### Anubis

- **Свои изображения Anubis**: показывает ваши `happy.webp`, `reject.webp` и `pensive.webp` на страницах проверки Anubis. По умолчанию: включено, если все три файла существуют и не пусты, иначе выключено. Переменная: `AUTH_REQUEST_ANUBIS_USE_CUSTOM_IMAGES`. Изображения кладутся в `public/anubis` в вашей папке данных.

Подробнее в вики: Forward-Authentication.
