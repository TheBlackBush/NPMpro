## Сертификаты и TLS

Значения по умолчанию для сертификатов, которые NPMpro запрашивает у вашего ACME-сервера (Let's Encrypt, если вы не задали другой через `ACME_SERVER`), для их степлинга и продления, а также сертификат, который отвечает для неизвестных хостов. Это раздел настроек, а не страница списка сертификатов.

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показан значок блокировки, например «Задано ACME_KEY_TYPE»). Некоторые поля зависят от других: одиночный `ACME_KEY_SIZE`, являющийся кривой ECDSA, оставляет тип ключа ECDSA, а Must-Staple оставляет OCSP stapling включённым. Всё, что не задано в контейнере, настраивайте в интерфейсе.

### Запросы сертификатов

Применяется со следующего запроса сертификата.

- **Тип ключа**: `ECDSA` (по умолчанию, рекомендуется: ключи меньше, рукопожатия быстрее) или `RSA` для клиентов, которые не умеют ECDSA. Переменная: `ACME_KEY_TYPE`.
- **Размер ключа**: кривая для ECDSA (`secp256r1`, `secp384r1`, `secp521r1`; по умолчанию `secp384r1`) или число бит для RSA (`2048`, `3072`, `4096`; по умолчанию `4096`). Переменная: `ACME_KEY_SIZE`.
- **Профиль ACME**: профиль, запрашиваемый у сервера, проверяется на сервере при сохранении. Если пусто, используется профиль сервера по умолчанию. В Let's Encrypt по умолчанию `shortlived`; клиенты, которым нужен Common Name, не работают с сертификатами `shortlived` и `tlsserver`. Переменная: `ACME_PROFILE` (`none` для пустого).
- **OCSP Must-Staple**: помечает новые сертификаты как must-staple и оставляет OCSP stapling включённым. Только для центров сертификации, которые это поддерживают (ZeroSSL); Let's Encrypt отклоняет такие запросы. По умолчанию: включено для Google Trust Services и ZeroSSL, иначе выключено. Переменная: `ACME_MUST_STAPLE`.
- **Проверять сертификат ACME-сервера**: по умолчанию включено. Выключайте только для частного ACME-сервера с самоподписанным сертификатом. Переменная: `ACME_SERVER_TLS_VERIFY`.

### Степлинг

Оба применяются после перезагрузки nginx, которую выполняет сохранение, и оба выключают сжатие TLS-сертификатов.

- **OCSP stapling для сертификатов ACME**: отправляет ответ OCSP вместе с сертификатами от ACME-сервера, если центр сертификации предлагает OCSP. По умолчанию: включено для Google Trust Services и ZeroSSL, иначе выключено. Переменная: `ACME_OCSP_STAPLING`.
- **OCSP stapling для своих сертификатов**: то же для загруженных сертификатов. По умолчанию: выключено. Переменная: `CUSTOM_OCSP_STAPLING`.

### Сертификат по умолчанию

- **Сертификат для неизвестных хостов и веб-интерфейса**: используется для имён хостов, для которых в NPMpro нет хоста, и на порту веб-интерфейса. По умолчанию: встроенный, сгенерированная заглушка. Переменная: `DEFAULT_CERT_ID` (ID сертификата; `0` это встроенный). Применяется после перезагрузки nginx, которую выполняет сохранение.

### Продление

- **Интервал проверки продления**: от 1 до 499 часов между проверками. Сертификат продлевается, только когда подходит срок. По умолчанию: 3. Переменная: `CERTBOT_RUN_INTERVAL`. Применяется сразу.

### ECH

- **Интервал ротации ключей ECH**: от 1 до 24 часов между запусками вашего скрипта ECH (`/data/tls/ech/cron.sh`). Используется, только если скрипт не пуст. По умолчанию: 1. Переменная: `ECH_ROTATION_INTERVAL`. Применяется сразу.
