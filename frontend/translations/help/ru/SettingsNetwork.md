## Сеть

Укажите NPMpro, каким прокси перед ним можно верить в отношении реального адреса клиента. Без этого журналы, списки доступа и CrowdSec видят адрес прокси, а не посетителя.

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показан значок блокировки, например «Задано TRUST_IP»). Всё, что не задано в контейнере, настраивайте в интерфейсе.

- **Доверенные IP прокси**: один адрес IPv4 или IPv6 либо диапазон CIDR в строке, например `10.0.0.0/8`, `192.168.1.5` или `fd00::/8`. Запросы с этих адресов могут передавать реальный IP клиента в `X-Forwarded-For`. Используйте для балансировщика нагрузки или туннеля, стоящего прямо перед NPMpro. По умолчанию: пусто (никому не доверяется). Переменная: `TRUST_IP` (через пробел). Применяется после перезагрузки nginx, которую выполняет сохранение.
- **Доверять Cloudflare**: загружает диапазоны IP Cloudflare, регулярно обновляет их и доверяет им, чтобы nginx видел реальные IP клиентов за Cloudflare. По умолчанию: выключено. Переменная: `TRUST_CLOUDFLARE`. Применяется после перезагрузки nginx, которую выполняет сохранение. Сначала прочитайте заметки о Cloudflare в вики (Security): размещение Cloudflare перед NPMpro имеет издержки для приватности и безопасности.

Доверяйте только адресам, которые вы контролируете или которым полностью верите. Доверенный адрес может выдать себя за любого посетителя.

Если при сохранении проверка nginx не пройдена, ничего не сохраняется, и показывается сообщение nginx.
