## nginx

Настройки самого nginx, которые относятся ко всем хостам: сколько рабочих процессов он запускает, правила TLS и необязательные модули. Сохранение проверяет конфигурацию и перезагружает nginx. Конфигурация, не прошедшая проверку, не применяется.

Переменная, заданная для контейнера, главнее интерфейса и блокирует поле (на поле показан значок блокировки, например «Задано NGINX_WORKER_PROCESSES»). Всё, что не задано в контейнере, настраивайте в интерфейсе. Каждая настройка здесь применяется после перезагрузки nginx, которую выполняет сохранение.

### Воркеры

- **Рабочие процессы**: «Автоматически (по одному на поток ЦП)» или число, не больше числа потоков ЦП, которые видит контейнер. По умолчанию: по одному на поток, но не больше 4. Переменная: `NGINX_WORKER_PROCESSES`.
- **Соединений на воркер**: сколько открытых соединений каждый воркер обрабатывает одновременно, от 64 до 65535. По умолчанию: 512. Переменная: `NGINX_WORKER_CONNECTIONS`.
- **Тайм-аут завершения воркеров**: как долго старые воркеры сохраняют свои соединения после перезагрузки. Значение времени nginx, например `30s`, `10m` или `1h`; `0` означает без ограничения. По умолчанию: `1h`. Переменная: `NGINX_WORKER_SHUTDOWN_TIMEOUT`.

### Журналирование

- **Журналировать ошибки «файл не найден»**: записывает строку в журнал ошибок для каждого запроса отсутствующего файла. По умолчанию: выключено. Переменная: `NGINX_LOG_NOT_FOUND`.

### TLS для всех хостов

Отключение TLS 1.2 или кривых NIST P закрывает доступ старым браузерам и клиентам. TLS 1.3 всегда включён.

- **Разрешить TLS 1.2**: по умолчанию включено. Переменная: `NGINX_DISABLE_TLS12` (инвертированная: `true` выключает TLS 1.2).
- **Только постквантовый обмен ключами**: разрешает только X25519MLKEM768, для чего нужен современный клиент. Выключает TLS 1.2 и кривые NIST P и блокирует их, пока включён. По умолчанию: выключено. Переменная: `NGINX_FORCE_X25519MLKEM768`.
- **Разрешить кривые NIST P**: secp521r1, secp384r1 и prime256v1 для обмена ключами, наряду с X25519. По умолчанию: включено. Переменная: `NGINX_TRUST_SECPR1`.
- **Разрешить подписи RSA PKCS#1**: для старых клиентов, которые не умеют RSA-PSS. По умолчанию: выключено. Переменная: `NGINX_TRUST_RSA_PKCS1`.

### Модули

По умолчанию все выключены. Включайте модуль, только если он нужен вашей собственной конфигурации. Если выключить модуль, который собственная конфигурация ещё использует, проверка nginx не пройдёт.

- **njs (JavaScript)**: директивы `js_*`. Переменная: `NGINX_LOAD_NJS_MODULE`.
- **Аутентификация LDAP**: директивы `auth_ldap`. Переменная: `NGINX_LOAD_LDAP_MODULE`.
- **Upstream с NTLM**: `ntlm` в блоках upstream. Переменная: `NGINX_LOAD_NTLM_MODULE`.
- **Статус трафика виртуальных хостов**: директивы `vhost_traffic_status_*`. Переменная: `NGINX_LOAD_VHOST_TRAFFIC_STATUS_MODULE`.
