## Сайт по подразбиране

Сайтът по подразбиране е това, което nginx отговаря, когато посетител стигне до NPMpro с име на хост, което никой хост не използва, или с IP адреса на сървъра. Изберете отговора тук. Прилага се за всички неизвестни имена.

Запазването първо тества новия избор с nginx. Ако тестът пропадне, нищо не се запазва, предишният сайт по подразбиране остава, а грешката на nginx е в журнала на контейнера.

- **Страница поздравление** (по подразбиране): показва приветствената страница на NPMpro.
- **404 страница**: отговаря със страница 404 Not Found.
- **Без отговор (444)**: затваря връзката без никакъв отговор. Използвайте го, за да не дадете на скенерите нищо за гледане. HTTPS заявките за неизвестни имена се отказват по време на TLS ръкостискането.
- **Пренасочване**: праща посетителите към друг адрес с временно пренасочване (302). Въведете пълен `http://` или `https://` URL без интервали, кавички и `; { } #`, до 255 знака.
- **Персонализиран HTML**: показва ваша собствена HTML страница. **HTTP код на състоянието** под нея е по избор, от 400 до 599. Оставете празно за 200 (OK).

При всеки избор освен „Без отговор“ заявките за неизвестни имена по обикновен HTTP първо се пренасочват към HTTPS, а HTTPS заявките използват сертификата, избран като **Сертификат по подразбиране** в Настройки, Сертификати и TLS.

Тази секция няма променливи на средата, затова промяната се прилага при запазване.
