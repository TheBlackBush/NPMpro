## API 액세스

모든 사용자의 모든 API 토큰입니다. 이 페이지는 관리자만 볼 수 있습니다.

토큰은 소유자가 사용자 메뉴의 **API 토큰**에서 만듭니다. 여기서는 각 토큰의 소유자, 권한, 만료일, 마지막 사용일, 생성일을 볼 수 있습니다.

- **폐기**는 토큰을 즉시 중지합니다. 그 토큰을 쓰는 스크립트와 AI 어시스턴트는 이후 인증 오류를 받습니다.
- 토큰은 소유자보다 많은 권한을 가질 수 없습니다. 관리자의 토큰은 **관리자** 스위치를 켠 경우에만 관리자로 동작하며, 사용자를 관리하는 토큰은 없습니다.
- 토큰의 생성, 폐기, 만료, 첫 사용은 감사 로그에 기록되며 사용자 옆에 토큰 이름이 표시됩니다.

API 문서는 새 탭에서 열립니다.
