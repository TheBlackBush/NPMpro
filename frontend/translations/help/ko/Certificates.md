## 인증서 도움말

### HTTP 인증서

HTTP 검증 방식의 인증서는 Certbot 서버가 **HTTPS가 아닌 HTTP로** 해당 도메인에 접속을 시도해 응답이 확인되면 인증서를 발급하는 방식입니다.

이 방식을 사용하려면 도메인에 대한 **프록시 호스트가 미리 생성되어 있어야 하며**, HTTP로 접근할 수 있어야 하고 NPMpro가 설치된 서버를 가리켜야 합니다. 인증서가 발급된 이후에는 해당 프록시 호스트에 HTTPS용 인증서를 적용할 수 있습니다.

다만, **인증서 자동 갱신을 위해서는 HTTP 접근이 계속 필요합니다.**

이 방식은 **와일드카드 도메인을 지원하지 않습니다.**

---

### DNS 인증서

DNS 검증 방식의 인증서는 DNS 공급자 플러그인을 사용해야 합니다. 이 플러그인은 도메인에 임시 DNS 레코드를 생성하며, Certbot는 해당 레코드를 조회해 도메인 소유 여부를 확인합니다. 검증이 성공하면 인증서가 발급됩니다.

이 방식은 인증서를 요청하기 전에 **프록시 호스트를 생성할 필요가 없으며**, 프록시 호스트에 HTTP 접근을 설정할 필요도 없습니다.

이 방식은 **와일드카드 도메인을 지원합니다.**

#### 저장된 DNS 자격 증명

DNS 공급자의 자격 증명은 인증서와 별도로 인증서 페이지의 **DNS 자격 증명** 탭에 저장됩니다.
인증서는 저장된 자격 증명 중 하나를 선택하기만 하므로 여러 인증서가 같은 자격 증명을 공유할 수 있습니다.

비밀 값은 암호화되어 저장되며 다시 표시되지 않습니다. 자격 증명을 편집할 때 비밀 값을 비워 두면
저장된 값이 유지됩니다. 암호화에 사용되는 키는 `/data/npmpro/dns-credentials.key` 파일입니다.
**이 파일을 데이터베이스와 함께 백업하세요.** 그렇지 않으면 복원 후 저장된 자격 증명을 읽을 수 없습니다.

양식이 없는 공급자는 INI 텍스트 상자를 사용하며, 해당 공급자의 자격 증명 파일 내용을
그대로 붙여 넣으면 됩니다.

### 사용자 지정 인증서

이 옵션을 사용하면 직접 보유한 인증 기관(CA)에서 발급한 TLS 인증서를 직접 업로드하여 사용할 수 있습니다.
