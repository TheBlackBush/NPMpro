## 고급

NPMpro의 동작을 사소하게 바꾸는 설정입니다.

컨테이너에 설정된 변수는 UI보다 우선하며 해당 필드를 잠급니다(필드에 "TZ(으)로 설정됨"과 같은 잠금 배지가 표시됩니다). 컨테이너에 설정되지 않은 항목은 UI에서 설정하세요.

- **시간대**: 컨테이너의 시간대입니다. 로그, GoAccess 보고서, 예약 백업 같은 예약 작업의 시간에 적용됩니다. `Europe/Berlin` 같은 이름을 사용하세요. 기본값: `UTC`. 변수: `TZ`. 컨테이너를 다시 시작한 후 적용됩니다. 저장하면 값이 저장되고, 이 섹션의 "적용하려면 컨테이너를 다시 시작하세요" 아래에 표시됩니다.
- **nginx 설정 서식 정리**: NPMpro가 작성하는 설정을 nginxbeautifier로 정리합니다. 표준이 아닌 사용자 지정 또는 고급 설정에서 실패하면 끄세요. 기본값: 켜짐. 변수: `DISABLE_NGINX_BEAUTIFIER`(반전: `true`이면 서식 정리가 꺼짐). 즉시 적용됩니다.
- **Gravatar 프로필 사진**: 업로드한 아바타가 없는 사용자에게 Gravatar 사진을 표시합니다. 사진을 가져오기 위해 NPMpro는 사용자 이메일 주소의 해시를 Gravatar에 보내므로, 이것이 문제가 된다면 끄세요. 기본값: 켜짐. 변수: `DISABLE_GRAVATAR`(반전: `true`이면 꺼짐). 즉시 적용됩니다. 사용자의 사진은 다음번 프로필 저장 때 바뀌며, 이미 가져온 사진은 그때까지 유지됩니다.
