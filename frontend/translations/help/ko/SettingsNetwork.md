## 네트워크

NPMpro 앞에 있는 프록시 중 실제 클라이언트 주소를 믿을 수 있는 것이 무엇인지 NPMpro에 알려 줍니다. 이 설정이 없으면 로그, 접근 정책, CrowdSec에는 방문자가 아니라 프록시의 주소가 보입니다.

컨테이너에 설정된 변수는 UI보다 우선하며 해당 필드를 잠급니다(필드에 "TRUST_IP(으)로 설정됨"과 같은 잠금 배지가 표시됩니다). 컨테이너에 설정되지 않은 항목은 UI에서 설정하세요.

- **신뢰할 프록시 IP**: 한 줄에 IPv4 또는 IPv6 주소 하나 또는 CIDR 범위 하나입니다(예: `10.0.0.0/8`, `192.168.1.5`, `fd00::/8`). 이 주소에서 온 요청은 `X-Forwarded-For`로 실제 클라이언트 IP를 전달할 수 있습니다. NPMpro 바로 앞에 있는 로드 밸런서나 터널에 사용합니다. 기본값: 비어 있음(아무도 신뢰하지 않음). 변수: `TRUST_IP`(공백으로 구분). 저장할 때 실행되는 nginx 리로드 후에 적용됩니다.
- **Cloudflare 신뢰**: Cloudflare IP 범위를 가져와 주기적으로 갱신하고 신뢰하므로, nginx가 Cloudflare 뒤에 있는 실제 클라이언트 IP를 볼 수 있습니다. 기본값: 꺼짐. 변수: `TRUST_CLOUDFLARE`. 저장할 때 실행되는 nginx 리로드 후에 적용됩니다. 먼저 위키의 Cloudflare 관련 안내(Security)를 읽으세요. NPMpro 앞에 Cloudflare를 두면 개인정보 보호와 보안 측면에서 대가가 따릅니다.

직접 관리하거나 완전히 신뢰할 수 있는 주소만 신뢰하세요. 신뢰받는 주소는 어떤 방문자라도 사칭할 수 있습니다.

저장 시 nginx 테스트가 실패하면 아무것도 저장되지 않고 nginx 메시지가 표시됩니다.

자세한 내용은 위키를 참조하세요: Security.
