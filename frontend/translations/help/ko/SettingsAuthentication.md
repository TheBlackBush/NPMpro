## 인증

OIDC 공급자(예: Authentik, Keycloak, Google)로 NPMpro 웹 UI에 로그인합니다. 비밀번호와 함께 또는 비밀번호 대신 사용할 수 있습니다. 이것은 포워드 인증이 아닙니다. 프록시 호스트를 보호하지 않습니다. 그에 대해서는 설정의 포워드 인증을 참조하세요.

컨테이너에 설정된 변수는 UI보다 우선하며 해당 필드를 잠급니다(필드에 "환경 변수로 설정됨"이 표시됩니다). 네 가지 연결 변수가 모두 설정되어 있으면 UI에서 활성화하지 않아도 OIDC가 활성 상태입니다. 컨테이너에 설정되지 않은 항목은 UI에서 설정하세요. 여기의 모든 설정은 저장할 때 적용됩니다.

### 공급자

- **OIDC 로그인 활성화**: 로그인 페이지에 로그인 버튼을 표시합니다.
- **발급자 URL**: 공급자의 디스커버리 기본 주소입니다(예: `https://accounts.example.com`). 변수: `OIDC_ISSUER_URL`.
- **클라이언트 ID**와 **클라이언트 시크릿**: 공급자에게서 받습니다. 시크릿은 암호화되어 저장되며 다시 표시되지 않습니다. 유지하려면 비워 두세요. 발급자 URL이나 클라이언트 ID를 변경하면 시크릿을 다시 입력하세요. 변수: `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`.
- **리디렉션 도메인**: 사람들이 NPMpro를 여는 데 사용하는 도메인이며, 포트가 443이 아니면 포트도 함께 적습니다. 콜백 URL을 만드는 데 쓰이므로 필수입니다. 변수: `OIDC_REDIRECT_DOMAIN`.
- **콜백 URL**: 읽기 전용입니다. 공급자에 리디렉션 URI로 등록하세요.
- **스코프**: 기본값은 `openid email profile`입니다. 공급자가 일부만 허용한다면 변경하세요(예: `openid email`).
- **연결 테스트**: NPMpro가 발급자에 접속할 수 있는지 확인합니다.

### 로그인 버튼

로그인 페이지의 버튼입니다. **표시 이름**("(으)로 로그인" 앞에 표시되는 텍스트), **색상**(프리셋 또는 직접 입력한 `#rrggbb`), **아이콘**(기본 제공, 256 KB 이하의 PNG, JPEG, WebP, SVG 업로드 또는 URL에서 다운로드)을 설정합니다. 미리보기가 표시됩니다.

### 로그인 규칙

- **인증된 이메일 필수**: 공급자가 이메일을 확인하지 않은 사용자를 거부합니다. 기본값: 켜짐. 변수: `OIDC_REQUIRE_VERIFIED_EMAIL`.
- **OIDC 후 2단계 인증 건너뛰기**: 공급자 자체의 다단계 인증 확인을 신뢰합니다. 기본값: 꺼짐. 변수: `OIDC_SKIP_MFA`.
- **비밀번호 로그인 비활성화**: OIDC로만 로그인할 수 있습니다. OIDC로 로그인한 세션에서만 켤 수 있습니다. 변수: `OIDC_DISABLE_PASSWORD`. 비밀번호 로그인을 복원하려면 `false`로 설정하고 컨테이너를 다시 만드세요.

### 새 사용자

- **첫 로그인 시 사용자 생성**(기본값: 꺼짐): 계정이 없는 사람에게 아래 권한으로 계정이 만들어집니다.
- **허용된 이메일 도메인**: 쉼표로 구분합니다. 비워 두면 모든 도메인을 허용합니다. 목록이 비어 있고 인증된 이메일도 필수가 아니면, 공급자가 받아들인 사람은 누구나 계정을 얻습니다.
- **새 사용자의 기본 권한**: 섹션별로 설정합니다. 새 사용자는 관리자가 되지 않습니다.

자세한 내용은 위키를 참조하세요: Authentication.
