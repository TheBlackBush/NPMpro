## 동적 DNS

NPMpro가 동적 DNS 탭(인증서)의 레코드가 공용 주소를 가리키도록 유지하는 방법입니다. 레코드를 활성화하기 전에는 아무것도 확인하지 않습니다.

컨테이너에 설정한 변수는 UI보다 우선하며 필드를 잠급니다(필드에 "DDNS_PERIOD로 설정됨" 같은 잠금 배지가 표시됩니다). 컨테이너에 설정하지 않은 항목은 UI에서 설정하세요.

- **확인 주기**: 레코드를 확인하는 주기로, `1m`에서 `24h`까지입니다(예: `5m`, `1h30m`). 기본값: `5m`. 변수: `DDNS_PERIOD`. 변경하면 타이머가 다시 시작됩니다.
- **대기 시간**: 한 레코드를 두 번 쓰는 사이의 최소 시간으로, 형식은 같습니다. 기본값: `5m`. 변수: `DDNS_COOLDOWN`.
- **IPv4 주소 서비스**와 **IPv6 주소 서비스**: 공용 주소로 응답하는 `https://` URL 2~10개입니다. 새 주소는 두 번째 서비스가 확인할 때만 기록되며, 바뀌지 않은 주소는 한 서비스로도 받아들여집니다. IPv6 서비스는 활성화된 레코드가 IPv6를 필요로 하는 동안에만 조회합니다. 변수: `DDNS_IPV4_SERVICES`, `DDNS_IPV6_SERVICES`(공백으로 구분). 이 호스트, 링크 로컬 주소(클라우드 메타데이터 등), 멀티캐스트 또는 예약 주소에 있는 서비스는 거부되며, 사설 LAN 주소는 허용됩니다.
- **확인용 DNS 서버**: 공급자에 묻기 전에 레코드 이름을 조회할 때만 사용합니다(스플릿 호라이즌). 주소 서비스와 공급자는 항상 컨테이너의 리졸버를 사용합니다. 비어 있으면 여기서도 컨테이너의 리졸버를 사용합니다. IPv4 주소 또는 대괄호로 묶은 IPv6 주소이며, 포트는 선택 사항입니다. 변수: `DDNS_RESOLVER`(공백으로 구분).

레코드는 동적 DNS 탭에서 레코드를 업데이트할 수 있는 공급자의 DNS 자격 증명으로 추가합니다.
