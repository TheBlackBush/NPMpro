## 리디렉션 호스트란?

리디렉션 호스트는 한 도메인의 방문자를 다른 주소로 보냅니다. 사이트의 도메인이 바뀌었는데 예전 링크가 계속 작동해야 하거나, `www`를 메인 이름으로 보내고 싶을 때 사용합니다.

호스트 메뉴의 **복제**를 사용하면 호스트를 새 추가 창으로 복사할 수 있습니다. 도메인은 활성화된 호스트 하나에만 속할 수 있으므로 복사본에는 도메인 이름이 들어 있지 않습니다.

### 세부 정보

- **도메인 이름**: 리디렉션되는 이름입니다. 필수입니다. 와일드카드는 새 인증서에서 DNS 챌린지를 사용할 때만 허용됩니다.
- **프로토콜 (Scheme)**: 대상의 프로토콜입니다. 기본값인 "유지(요청과 동일)"는 방문 시의 `http` 또는 `https`를 그대로 유지합니다. 또는 `http`나 `https`를 선택할 수 있습니다.
- **전달할 도메인**: 방문자를 보낼 도메인입니다(예: `example.com`). 필수입니다.
- **HTTP 코드**: 응답 코드입니다. 기본값은 301 Moved permanently입니다. 다른 선택지는 302 Moved temporarily, 303 See other, 307 Temporary redirect, 308 Permanent redirect입니다. 이전이 영구적이라면 301 또는 308을 사용하세요. 브라우저와 검색 엔진이 이를 기억합니다.
- **그룹**: 긴 목록을 정돈해 주는 자유 형식 레이블입니다. 사용 중인 것을 고르거나 새 이름을 입력하세요.
- **요청 경로 유지**(기본값은 꺼짐): 원래 경로와 쿼리를 대상에 덧붙입니다. 켜면 `old.example/a?b=1`이 `new.example/a?b=1`로 이동합니다. 꺼져 있으면 모든 방문자가 대상의 시작 페이지에 도착합니다.

### TLS

- **TLS 인증서**: 없음, 새 인증서 요청 또는 기존 인증서. 아래 옵션에는 인증서가 필요합니다.
- **mTLS 인증서**: 클라이언트 인증 기관입니다. **mTLS 선택 사항으로 설정**을 켜면 클라이언트 인증서가 없는 방문자도 들어올 수 있습니다.
- **HTTPS 강제 적용**: 먼저 HTTP를 HTTPS로 리디렉션합니다.
- **HTTP/3 지원**: HTTP/3(QUIC)를 허용합니다.
- **HSTS 활성화(2년)**: HTTPS 강제 적용이 필요합니다. **HSTS 하위 도메인+Preload**에는 HSTS가 필요합니다.
- 새 인증서의 경우: **키 재사용(권장하지 않음)**과 **DNS 챌린지 사용**이 있으며, 공급자, 자격 증명 및 전파 대기 시간(초)을 지정합니다.

모든 TLS 옵션은 기본값이 꺼짐입니다.

### 고급

호스트의 server 블록 안에 추가되는 사용자 지정 nginx 설정입니다. 관리자만 변경할 수 있으며, 다른 사용자는 읽기 전용으로 봅니다.

자세한 내용은 위키를 참조하세요: Host options.
