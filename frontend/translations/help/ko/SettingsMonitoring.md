## 로그 및 모니터링

로그 파일, GoAccess 로그 보고서, 모니터링 페이지의 기반이 되는 트래픽 통계입니다.

컨테이너에 설정된 변수는 UI보다 우선하며 해당 필드를 잠급니다(필드에 "LOGROTATE(으)로 설정됨"과 같은 잠금 배지가 표시되며, 통계에는 "환경 변수로 설정됨"이 표시됩니다). 컨테이너에 설정되지 않은 항목은 UI에서 설정하세요. "다시 시작 필요"로 표시된 설정은 즉시 저장되지만 컨테이너가 시작될 때 읽힙니다. 이 경우 이 섹션의 "적용하려면 컨테이너를 다시 시작하세요" 아래에 나열됩니다.

### 로그 파일

- **로그 파일 쓰기**: nginx 오류, 스트림, 액세스 로그를 `/data/nginx/logs`에 기록하고 매일 순환합니다. 기본값: 꺼짐. 변수: `LOGROTATE`. 저장할 때 실행되는 nginx 리로드 후에 적용됩니다. GoAccess가 실행되는 동안에는 켜진 상태로 유지됩니다.
- **보관할 로그 순환 수**: 가장 오래된 파일이 삭제되기 전까지 순환된 로그 파일을 몇 개 보관할지 정합니다. 1~1000. 기본값: 3. 변수: `LOGROTATIONS`. 즉시 적용됩니다.

### GoAccess

- **GoAccess 보고서**: 관리자를 위한 웹 로그 보고서인 GoAccess를 웹 UI의 `/goaccess`에서 실행합니다. 기본값: 꺼짐. 변수: `GOA`. 컨테이너를 다시 시작한 후 적용됩니다. 트래픽 통계를 켜지는 않습니다.

보고서를 켜면 다음 옵션이 표시됩니다. 모두 컨테이너를 다시 시작한 후 적용됩니다. 변수 하나인 `GOACLA`가 이 옵션 전체를 직접 지정한 GoAccess 옵션으로 대체하고 이들을 잠급니다.

- **보고서 데이터 보관**: 1~366일. 기본값: 30.
- **방문자 IP 익명화**: 끄기, 레벨 1(기본값), 레벨 2(강력), 레벨 3(엄격). 레벨 1은 IPv4의 마지막 1바이트(IPv6는 마지막 64비트), 레벨 2는 2바이트(80비트), 레벨 3은 3바이트(96비트)를 숨깁니다.
- **쿼리 문자열 제거**: 보고서의 URL에서 쿼리 문자열을 제거하므로 URL 속 토큰이 저장되지 않습니다. 기본값: 켜짐.
- **운영 체제 전체 버전**: 계열만이 아니라 전체 버전을 표시합니다. 기본값: 켜짐.
- **호스트 이름 확인**: 방문자 IP의 호스트 이름을 조회합니다. 이를 위해 DNS 쿼리를 보냅니다. 기본값: 켜짐.

### 모니터링

모니터링 페이지의 트래픽 탭을 제어합니다. 모두 저장하면 즉시 적용됩니다. 변수: `TRAFFIC_STATS`, `TRAFFIC_RETENTION_DAYS`, `TRAFFIC_SHOW_IPS`, `TRAFFIC_UNIQUE_VISITORS`, `TRAFFIC_VISITORS_CAP`.

- **트래픽 통계**: nginx 액세스 로그를 읽어 호스트, 상태, 국가, 네트워크별로 요청 수를 집계합니다. 기본값: 꺼짐. 끄면 새로운 집계가 중단됩니다. 저장된 통계는 대화 상자에서 "저장된 통계도 삭제"를 선택하지 않는 한 기간이 지날 때까지 유지됩니다.
- **통계 보관 기간**: 7~365일. 기본값: 30. 분 단위 데이터는 24시간, 시간 단위 데이터는 이 일수만큼 보관됩니다.
- **방문자 IP 표시**: 상위 IP를 나열하기 위해 방문자 IP를 시간별로 저장합니다. 기본값: 개인정보 보호를 위해 꺼짐. 끄면 저장된 IP가 삭제됩니다.
- **순 방문자 집계**: 순 방문자를 세기 위해 호스트와 날짜별로 각 방문자 IP의 키 해시를 저장합니다. 기본값: 꺼짐. 끄면 해시가 삭제됩니다.
- **호스트별 일일 방문자 한도**: 1000~1000000. 기본값: 100000. 한도에 도달한 호스트는 그날 새 방문자 집계를 중단하고 더하기 기호를 표시합니다.

국가와 네트워크에는 GeoIP 데이터베이스가 필요합니다(설정, GeoIP).

자세한 내용은 위키를 참조하세요: Monitoring.
