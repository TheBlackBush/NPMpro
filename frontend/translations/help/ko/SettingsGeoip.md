## GeoIP

NPMpro는 무료 GeoIP 데이터베이스(DB-IP Lite 또는 MaxMind GeoLite2)를 직접 다운로드하고 서버에서 국가와 네트워크를 조회하므로 방문자 IP가 외부로 전송되지 않습니다. 별도의 geoipupdate 컨테이너가 필요 없습니다. 이 데이터베이스는 모니터링 지도와 목록, GoAccess, nginx 국가 규칙에 사용됩니다.

컨테이너에 설정된 변수는 UI보다 우선하며 해당 필드를 잠급니다(필드에 "환경 변수로 설정됨"이 표시됩니다). 컨테이너에 설정되지 않은 항목은 UI에서 설정하세요. 저장하면 백그라운드에서 다운로드가 시작되며, 완료되면 아래 상태가 갱신됩니다.

### 제공자

- **DB-IP Lite**가 기본값입니다. 무료이며 계정이 필요 없고, 매월 새 파일이 나옵니다(NPMpro는 일주일에 한 번 확인합니다).
- **MaxMind GeoLite2**도 그대로 사용할 수 있습니다. 무료 계정과 라이선스 키가 필요하며 일주일에 두 번 업데이트됩니다.

한 번에 하나의 제공자만 활성화되며 해당 제공자의 데이터베이스만 사용합니다. 다른 제공자의 파일은 디스크에 남아 있으므로 다시 전환해도 새로 다운로드할 필요가 없습니다. GoAccess는 다음 컨테이너 시작 시 전환을 반영합니다. 변수: `GEOIP_PROVIDER`(`dbip` 또는 `maxmind`).

### DB-IP 데이터베이스

- **Country**: 지도, 국가 목록, 접근 정책의 국가 규칙용 국가 정보입니다.
- **ASN**: 네트워크 목록용 네트워크(AS 번호와 이름)입니다.

둘 다 기본으로 켜져 있습니다. 변수: `GEOIP_DBIP_EDITIONS`.

### MaxMind 계정

무료 MaxMind 계정과 라이선스 키가 필요합니다(MaxMind에서: Account, Manage license keys). 페이지에 가입 링크가 있습니다.

- **계정 ID**: 변수 `GEOIP_ACCOUNT_ID`.
- **라이선스 키**: 암호화되어 저장되며 다시 표시되지 않습니다. 저장된 키를 복호화할 수 없으면 다시 입력하세요. 변수: `GEOIP_LICENSE_KEY`.

### 데이터베이스

- **GeoLite2 Country**: 지도, 국가 목록, nginx 국가 규칙에 쓰이는 국가입니다. 기본적으로 켜져 있습니다.
- **GeoLite2 ASN**: 네트워크 목록에 쓰이는 네트워크(AS 번호와 이름)입니다. 기본적으로 켜져 있습니다.
- **GeoLite2 City**: 선택 사항이며 GoAccess에 쓰이는 도시입니다. 다운로드 크기가 훨씬 큽니다. 기본적으로 꺼져 있습니다.

변수: `GEOIP_EDITIONS`, 공백으로 구분합니다(예: `GeoLite2-Country GeoLite2-ASN`). 선택한 데이터베이스가 없으면 아무것도 다운로드하거나 업데이트하지 않으며, 이미 다운로드한 데이터베이스는 유지됩니다.

### 상태

마지막 업데이트, 마지막 확인, 마지막 오류를 표시합니다. NPMpro는 제공자, 계정 또는 데이터베이스를 변경할 때, **지금 업데이트**를 클릭할 때, 그리고 자동으로 활성 제공자의 데이터베이스를 업데이트합니다. 자동 업데이트는 MaxMind는 3일마다, DB-IP는 7일마다입니다(DB-IP는 매월 새 파일을 공개하며 더 새로운 파일만 다운로드합니다). 자동 업데이트에 실패하면 24시간 후에 다시 시도합니다. **지금 업데이트**에는 MaxMind의 경우 저장된 계정 ID와 라이선스 키가, DB-IP의 경우 하나 이상 선택된 데이터베이스가 필요합니다.

데이터베이스가 없으면 지도와 국가 및 네트워크 목록은 숨겨지며, 나머지는 정상적으로 작동합니다.

자세한 내용은 위키를 참조하세요: Monitoring.
