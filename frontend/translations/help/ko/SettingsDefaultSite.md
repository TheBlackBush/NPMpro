## 기본 사이트

기본 사이트는 방문자가 어떤 호스트도 사용하지 않는 호스트 이름이나 서버의 IP 주소로 NPMpro에 접속했을 때 nginx가 응답하는 내용입니다. 여기서 응답을 선택합니다. 알 수 없는 모든 이름에 적용됩니다.

저장하면 먼저 nginx로 새 선택을 테스트합니다. 테스트가 실패하면 아무것도 저장되지 않고 이전 기본 사이트가 유지되며, nginx 오류는 컨테이너 로그에 남습니다.

- **축하 페이지**(기본값): NPMpro 환영 페이지를 표시합니다.
- **404 페이지**: 404 Not Found 페이지로 응답합니다.
- **응답 없음 (444)**: 아무 응답 없이 연결을 닫습니다. 스캐너에게 아무것도 보여 주고 싶지 않을 때 사용합니다. 알 수 없는 이름에 대한 HTTPS 요청은 TLS 핸드셰이크 중에 거부됩니다.
- **리다이렉트**: 임시 리디렉션(302)으로 방문자를 다른 주소로 보냅니다. 공백, 따옴표, `; { } #`가 없는 전체 `http://` 또는 `https://` URL을 255자 이내로 입력합니다.
- **사용자 지정 HTML**: 직접 만든 HTML 페이지를 표시합니다. 그 아래의 **HTTP 상태 코드**는 선택 사항이며 400~599입니다. 비워 두면 200(OK)입니다.

응답 없음을 제외한 모든 선택에서, 알 수 없는 이름에 대한 일반 HTTP 요청은 먼저 HTTPS로 리디렉션되고, HTTPS 요청은 설정의 인증서 및 TLS에서 **기본 인증서**로 선택한 인증서를 사용합니다.

이 섹션에는 환경 변수가 없으므로 변경 사항은 저장할 때 적용됩니다.
