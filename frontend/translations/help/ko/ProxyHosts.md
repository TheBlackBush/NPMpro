## 프록시 호스트란?

프록시 호스트는 웹 서비스의 출입구입니다. 방문자가 NPMpro에서 도메인을 열면 NPMpro가 그 요청을 뒤에 있는 서비스로 전달합니다. TLS(HTTPS)가 없는 서비스에 TLS를 추가할 수도 있습니다. 프록시 호스트는 NPMpro에서 가장 흔한 사용 방식입니다.

호스트 메뉴의 **복제**를 사용하면 호스트를 새 추가 창으로 복사할 수 있습니다. 도메인은 활성화된 호스트 하나에만 속할 수 있으므로 복사본에는 도메인 이름이 들어 있지 않습니다.

### 세부 정보

- **도메인 이름**: 방문자가 사용하는 이름입니다. 필수입니다. 새 인증서의 경우 와일드카드(`*.example.com`)에는 DNS 챌린지가 필요합니다.
- **프로토콜 (Scheme)**: NPMpro가 서비스와 통신하는 방식입니다. `http://`, `https://`, `grpc://`, `grpcs://`, `path`(폴더의 파일이나 PHP 제공) 또는 `empty`(업스트림 없음) 중에서 선택합니다. 기본값은 `http://`입니다. 프로토콜을 바꾸면 맞지 않는 옵션은 꺼집니다.
- **전달 호스트 이름 / IP / 경로**: 서비스의 주소입니다. `127.0.0.1/path`처럼 하위 경로를 추가할 수 있습니다. `path`에서는 대신 폴더를 입력합니다. 파일은 `/var/www` 아래에 마운트하세요. 그 밖의 폴더는 관리자만 사용할 수 있습니다. `cu_`로 시작하는 이름은 직접 만든 nginx 업스트림 블록을 가리킵니다(위키의 Load balancing 참조).
- **전달할 포트**: 선택 사항입니다. `path`에서는 PHP 버전입니다.
- **그룹**: 긴 목록을 정돈해 주는 자유 형식 레이블입니다.
- **옵션**(모두 기본값은 꺼짐):
  - **noindex 헤더 전송 및 일부 봇 사용자 에이전트 차단**: 검색 엔진에 사이트를 색인하지 않도록 요청하고 일부 크롤러를 차단합니다.
  - **CrowdSec AppSec 비활성화**: 이 호스트에 대해서만 CrowdSec AppSec을 끕니다. AppSec이 설정되어 있을 때만 효과가 있습니다.
  - **요청 버퍼링 비활성화**와 **응답 버퍼링 비활성화**: http 및 https 업스트림용입니다. 빠르고 안정적인 회선에서 스트리밍하거나 큰 파일을 업로드하는 경우가 아니라면 버퍼링을 켜 두세요. 요청 버퍼링을 끄면 AppSec도 꺼집니다.
  - **업스트림 압축 활성화**: 서비스가 자체 응답을 압축하도록 허용합니다. 서비스에 필요하지 않다면 꺼 두세요. `path`와 `empty`에서는 사용할 수 없습니다.
  - **fancyindex 활성화**: 폴더에 인덱스 파일이 없을 때 파일 목록을 보여 줍니다. `path`에서만 사용할 수 있습니다.
- **X-Frame-Options**: `SAMEORIGIN`(기본값), `DENY`, `none`(헤더 제거) 또는 `upstream`(서비스가 보내는 값 유지).
- **Auth Request**: 호스트 앞에 로그인 또는 봇 검사를 둡니다(Anubis, Tinyauth, OAuth2 Proxy, VoidAuth, Authelia, Authentik). 기본값은 `none`입니다. **Auth Request 업스트림**은 선택 사항이며, 비워 두면 설정의 포워드 인증 기본값을 사용합니다.
- **전역 접근 정책**: **누구나 접근 가능**(기본값, 로그인 없음) 또는 **사용자 지정**(접근 정책 하나 이상).

웹소켓은 항상 켜져 있습니다.

### 사용자 지정 위치

위치는 호스트의 한 경로(예: `/api/`)를 다른 서비스로 보냅니다. 각 위치에는 **활성화됨**, 선택적 일치 유형(`=`, `~`, `~*`, `^~`, `@`)이 있는 경로, 자체 프로토콜, 호스트, 포트, 옵션, Auth Request 및 접근 정책이 있습니다. 접근 정책은 **전역**으로 설정할 수 있으며, 이 경우 호스트의 목록을 사용합니다. 호스트의 Auth Request는 상속하지 않습니다. 접두사 일치를 원하는 경우가 아니라면 경로 끝에 슬래시를 붙이세요. 관리자는 톱니바퀴 버튼으로 위치별 사용자 지정 nginx 설정을 추가할 수 있습니다.

### TLS

- **TLS 인증서**: 없음, 새 인증서 요청 또는 기존 인증서. 아래 옵션에는 인증서가 필요합니다.
- **mTLS 인증서**: 클라이언트 인증 기관입니다. **mTLS 선택 사항으로 설정**을 켜면 인증서가 없는 방문자도 들어올 수 있습니다. **mTLS로 Auth Request 우회**를 켜면 유효한 인증서를 가진 방문자는 Auth Request를 건너뜁니다.
- **HTTPS 강제 적용**은 HTTP를 HTTPS로 리디렉션합니다. **HTTP/3 지원**은 HTTP/3(QUIC)를 허용합니다.
- **HSTS 활성화(2년)**: HTTPS 강제 적용이 필요합니다. **HSTS 하위 도메인+Preload**에는 HSTS가 필요합니다.
- 새 인증서의 경우: **키 재사용(권장하지 않음)**과 **DNS 챌린지 사용**이 있으며, 공급자, 자격 증명 및 전파 대기 시간(초)을 지정합니다.

### 고급

호스트 전체(server 블록)와 메인 위치 `location /`에 대한 사용자 지정 nginx 설정입니다. 관리자만 변경할 수 있습니다.

자세한 내용은 위키를 참조하세요: Host options.
